# بوابة رفيقي للحياة المدرسية

نسخة ويب تعليمية مستوحاة من منصة "الحياة المدرسية" لوزارة التربية التونسية، مبنية بتقنية **PostgreSQL + Prisma + Node.js (Express) + React (Vite)** مع دعم عربي RTL كامل.

## التشغيل بسهولة
```bash
chmod +x start.sh
./start.sh
```
ثم افتح المتصفح على: **http://localhost:5173**

### أو عبر Docker (تشغيل كامل بضغطة واحدة)
```bash
JWT_SECRET=$(openssl rand -hex 32) docker compose up --build -d
```
> `JWT_SECRET` **إلزامي** الآن — بدونه يرفض `docker compose` الإقلاع (لا قيمة افتراضية ضعيفة).
> في الإنتاج عرّف أيضاً `ALLOWED_ORIGINS` بدومين الواجهة، واختر مزود دفع حقيقياً
> (`PAYMENT_PROVIDER`) — المزود `DEMO` معطّل تلقائياً في `NODE_ENV=production`
> إلا إذا ضبطت `ALLOW_DEMO_PAYMENTS=true` صراحةً (للعروض التجريبية فقط).
> وثائق Swagger معطّلة في الإنتاج (متاحة في التطوير فقط على `/api-docs`).

ثم افتح **http://localhost:5173** (API على 3001، قاعدة بيانات على 5432).
يُنشئ الحاويات الثلاث (postgres + api + web)، يُطبّق الهجرات ويبذر البيانات تلقائياً
(البذر قابل لإعادة التشغيل بأمان). لإيقافه: `docker compose down`.

## فضاء الأستاذ (20 تبويب)

- **التكليفات المنزلية** — إسناد تكليفات للأقسام (أسئلة موضوعية)، متابعة الإنجاز تلميذاً تلميذاً، تصحيح آلي فوري + تصحيح يدوي بدرجة وملاحظة
- **التحليلات** — تقرير قسم (إنجاز/متوسط/معرضون للخطر/متوسطات التكليفات)، تقرير تلميذ (قوة/ضعف حسب المواد، منحنى أداء، تنبيهات تعثر مبكر)، وتصدير CSV/PDF بخط عربي
- **تحليل الوحدات** — أداء القسم/الدرس حسب الوحدات
- **الاختبارات** — إنشاء اختبارات سريعة (QCM / صح-خطأ / ترتيب / استخراج / أكمل) مع تصحيح آلي فوري
- **الاختبارات الرسمية** — بنك اختبارات رسمية (مواد × ثلاثيات)، إسنادها لأقسام، نشرها، طباعتها بترويسة رسمية وسلّم تنقيط
- **مواد الأقسام** — برمجة المواد لكل قسم (تلميذ القسم لا يشاهد سوى المواد المبرمجة لمستواه)
- **التصحيح** — تصحيح محاولات التلاميذ (يدوي + اقتراح رفيقي AI) + **صندوق الأوراق الممسوحة** (تصحيح أوراق الاختبار الورقي الممسوحة PDF)
- **النتائج** — نتائج التلاميذ الفردية والجماعية
- **المعدلات** — المعدلات والمتوسطات حسب القسم
- **المذكرات** — توليد مذكرة درس آليًا حسب قالب رسمي (تُشتق من محتوى المنهج عند توفره في `backend/curriculum/`)
- **الموارد التعليمية** — ورقة عمل / واجب منزلي / بطاقات مراجعة / عرض تقديمي تُولَّد آليًا
- **خطة الدرس** — خطة حصّة (45 دقيقة) بمراحل وزمن وأهداف وتقويم
- **التخطيطات السنوية** — مخططات جاهزة (رياضيات / قراءة / إيقاظ علمي) قابلة للتعديل
- **رفيقي AI** — إدخال مفتاح Gemini اختياري (يُخزَّن على الخادم فقط)، توليد اختبارات/قصص، مراجعة جودة المحتوى — المنصة تعمل كاملة بدونه
- **جدول الأوقات** — جدول أسبوعي قسم بقسم (6 أيام × 6 فترات) يظهر فورًا للتلاميذ
- **الحصص المباشرة** — جدولة حصص حية بقسم (فيديو/صوت)، بدء وإنهاء وإلغاء، حضور فوري عبر WebSocket، وتسجيل تلقائي متاح للتلاميذ بعد الانتهاء (مزوّدا تجريبي LOCAL + LiveKit) — التفاصيل في `docs/STAGE5.1_DONE.md`
- **تفاعلات الحصة** — دردشة حية ورفع اليد ومشاركة شاشة داخل البث المباشر مع تحكم الأستاذ — التفاصيل في `docs/STAGE5.2_DONE.md`
- **مركز الرسائل والإشعارات** — إعلانات الإدارة تصلك كإشعار داخل المنصة (مع إشعارات فورية عبر WebSocket وبريد إلكتروني/SMS اختياري حسب تفضيلاتك)، ومركز رسائل موحّد يجمع الإعلانات والإشعارات والمراسلات — التفاصيل في `docs/STAGE5.3_DONE.md`
- **اقتراحات** — اقتراحات بيداغوجية جاهزة

## فضاء التلميذ

- **نظام تحفيزي** — XP وعملات ومستويات (كل 100 XP = مستوى) وشارات (أول اختبار، علامة ممتازة، سلسلة أيام...)
- **موادي** — التلميذ يشاهد فقط المواد المبرمجة لقسمه (ربط: تلميذ ← قسم ← مواد ← أساتذة) مع دروس كل مادة
- **اختباراتي** — إنجاز اختبارات القسم مع تصحيح فوري ونقاط خبرة
- **تكليفاتي** — استقبال التكليفات المنزلية من الأستاذ، إنجازها، ومراجعة التصحيح الآلي/اليدوي
- **اختبار ورقي** — مسح ورقة الاختبار بالكاميرا أو رفع صور، تحسين تلقائي للصور (تفتيح + تباين)، دمجها في PDF واحد بترقيم صفحات، وإرسالها لصندوق تصحيح الأستاذ مباشرة
- **قسم اللعب** — 3 ألعاب تعليمية (حساب سريع / تركيب كلمات / اختبار ذاكرة) مع نقاط وشارات، حد يومي (10 جولات)، وترتيب ودّي بين تلاميذ نفس القسم
- **كتبي التفاعلية** — كتب PDF لمطالعة وتحميل (الأنيس / الرياضيات / علومي / قصص)
- **خطة تعلّمي** — خطة تعلّم شخصية ديناميكية تُبنى من سجلاتك الحقيقية (واجبات/اختبارات/مراجعة ذكية/دروس): ملف لكل مادة بحالة (ضعيف/متوسط/متين) ومعدل الإجادة، برنامج يومي مقترح (مراجعة/درس/تمرين)، تعديل مستوى الصعوبة تلقائياً حسب دقتك في المراجعة الذكية، وجلسة مقترحة تبدأ من أضعف مادة
- **فيديوهاتي** — فيديوهات قصيرة (3-5 دقائق) من كتالوج مصادر خارجية معتمدة مع فلاتر (مادة × مستوى) ومشغّل مدمج، إضافة إلى تبويب «فيديوهات» داخل عارض الدرس التفاعلي
- **اسأل رفيقي** — بومة معلّمة، محادثة عربية مبسّطة مع **قراءة صوتية تلقائية** (Web Speech API)
- **التوأم الرقمي** — تحليلات الأداء ونقاط القوة/الضعف وسجل الأنشطة
- **جدول أوقاتي** — جدول قسمه مباشرة
- **حصصي المباشرة** — حصص قسمه الحية (انضمام/متابعة)، قائمة حضور فورية، والتسجيلات المتاحة للشغيل والتحميل بعد انتهاء الحصة

## فضاء الولي

- متابعة تقدم الأبناء (XP، مستوى، اختبارات، آخر النتائج، شارات)
- **الدفع الإلكتروني** — سداد اشتراكات الأبناء إلكترونيا في وضع اختبار (مزود تجريبي DEMO + Stripe/STB)، مع CAPTCHA وسجلات تدقيق، وتفعيل فوري عبر Webhook
- **فواتيري الرقمية** — فواتير PDF تصدر تلقائيا بعد كل دفع ناجح (تحميل مباشر)
- **التجديد التلقائي** — تجديد الاشتراكات تلقائيا قبل انتهائها بـ 7 أيام (دفع عبر الاشتراك نفسه) مع إمكانية الإلغاء/إعادة التفعيل، وأكواد تخفيض ومنح دراسية عند الدفع
- متابعة **التكليفات المنزلية** ودرجاتها ومواعيد التسليم لكل ابن
- **تحليلات الأداء** — نقاط القوة/الضعف حسب المواد ومنحنى الأداء وتنبيهات التعثر لكل ابن
- متابعة حالة **الأوراق الممسوحة** المرسلة من الابن (مرسل / قيد التصحيح / مصحح + النتيجة)
- تقارير أسبوعية بمقارنة دقة هذا الأسبوع بالأسبوع الماضي
- مراسلة المعلم مباشرة مع مؤشر "يكتب الآن..." في الزمن الحقيقي (WebSocket)
- **حصصي المباشرة** — متابعة حصص قسم الأبناء المباشرة (انضمام/مشاهدة) وقائمة حضور فورية وتسجيلات متاحة للشغيل والتحميل

## لوحة الإدارة (مدير المدرسة / مدير عام)

- لوحة قيادة شاملة: إجماليات، أداء حسب القسم، مخطط اتجاه المحاولات، نشاط أخير
- تنبيهات تلقائية: تلاميذ بلا قسم، أقسام ضعيفة، رسائل معلقة
- **اللوحة المالية** (مدير عام/نظامي): نظرة عامة على الإيراد (ملخص + منحنى شهري 12 شهرا + توزيع حسب الخطة والطريقة)، عمليات الدفع والفواتير (تحميل PDF / إرجاع)، **تسوية مالية** (مطابقة العمليات/الفواتير/نوايا الدفع وكشف الفروقات)، **كشف الشذوذ** (9 قواعد آلية مع معالجة موثّقة)، وتصدير **تقارير مالية PDF/CSV** بفلترة الفترة/السنة الدراسية — التفاصيل في `docs/STAGE4.3_DONE.md`

## فضاء النظام (Super Admin)

- إدارة المستخدمين والأدوار والبحث

## المرحلة 8 — فضاء التلميذ: مواده فقط + قسم اللعب

### 8أ — عرض المواد حسب المستوى/القسم
- جدول `ClassSubject` يربط: قسم ← مادة ← أستاذ ← مستوى دراسي (من مستوى القسم).
- الأستاذ يدير مواد أقسامه من تبويب **مواد الأقسام** (إضافة / حذف)، والمدير العام/مدير المدرسة يدير الكل.
- التلميذ في تبويب **موادي** يشاهد فقط المواد المبرمجة لقسمه، مع دروس كل مادة (من جدول `Lesson` حسب المادة والمستوى).

### 8ب — قسم اللعب
- 3 ألعاب: **الحساب السريع** (عمليات جمع/طرح)، **تركيب الكلمات** (ترتيب الحروف)، **اختبار الذاكرة** (طابق الأزواج).
- جدول `GameResult` يسجل كل جولة (لعبة، نتيجة، عدد صحيح، مدة) — **معزول تماما عن النتائج الأكاديمية الحقيقية**.
- كل جولة تمنح XP (3 نقاط) وعملات عبر نظام التحفيز، مع الحد اليومي 10 جولات لضبط وقت اللعب.
- **ترتيب ودّي** بين تلاميذ نفس القسم (المجموع الكلي للنقاط) بدون أي ضغط.

## المرحلة 9 — اختبار ورقي → مسح → PDF → إرسال للأستاذ

1. الأستاذ ينشر اختبارا في فضاء التلميذ (اختبارات سريعة أو رسمية).
2. التلميذ يطبع الورقة، يجاوب، ثم يفتح تبويب **اختبار ورقي**:
   - زر **مسح بالكاميرا** (`capture="environment"`) أو **رفع من الجهاز** (متعدد الصفحات).
   - تحسين تلقائي للصورة على المتصفح: تفتيح + تباين + تحويل رمادي (Canvas API) مع معاينة حية.
   - حد أقصى 10 صفحات.
3. الخادم يدمج الصور في **PDF واحد منظم** (`pdf-lib`) — كل صورة في صفحة، بترتيب الرفع.
4. اسم الملف يتولّد تلقائيا: `الاسم_اللقب_المادة_عنوان_الاختبار_التاريخ.pdf` (مثال: `احمد_التلميذ_الرياضيات_اختبار_رقم_1_2026-09-15.pdf`).
5. يصل مباشرة لصندوق **التصحيح** متاع الأستاذ المعني (أستاذ المادة حسب `ClassSubject`، أو أستاذ القسم).
6. الحالات: `مرسل` → `قيد التصحيح` → `مصحح`، مع نتيجة /20 وملاحظة، وإشعار للتلميذ **والولي** فور التصحيح.

## المرحلة 10 — الوثائق الإدارية من الولي لمدير المدرسة

1. الولي يفتح تبويب **الوثائق الإدارية**، يختار نوع الوثيقة (شهادة طبية، وثيقة تسجيل، مطلب استثناء، مطلب انتقال، طلب شهادة مدرسية، ملف منحة...) مع التلميذ المعني، ويرفق ملف PDF/صورة وملاحظة قصيرة.
2. الوثيقة تصل مباشرة لصندوق **الوثائق الإدارية** عند مدير المدرسة (والمدير العام) بحالة `قيد الدراسة`.
3. مدير المدرسة يطّلع على الملف، ويقبل أو يرفض مع رد مكتوب.
4. الولي يتوصل بإشعار فوري بنتيجة المراجعة، ويشاهد الرد في الأرشيف مع حالة كل وثيقة.
5. أرشيف كامل لكل وثائق الأبناء — مفيد وقت التحويل المدرسي، منح، استثناءات...
- حالات الوثيقة: `قيد الدراسة` → `قيد المراجعة` → `مقبولة` / `مرفوضة`.
- جدول `ParentDocument` جديد + مسارات `/api/parent/documents` و `/api/director/documents`.

## المرحلة 11 — أفكار إضافية (من تجربة المنصات العالمية)

### أ) الحضور والغياب الرقمي
- الأستاذ يسجل الحضور يوميًا من تبويب **الحضور والغياب** (قسم × تاريخ)، بضغطة واحدة حاضر/غائب مع ملاحظة.
- يتوصل الولي بإشعار فوري في صورة غياب، ويشاهد ملخص الحضور والغياب في **تقدم الأبناء** (آخر 30 يومًا).
- جدول `AttendanceRecord` جديد + إشعارات للأولياء.

### ب) التقويم المدرسي الموحّد
- عطل، اختبارات، اجتماعات وأنشطة — ينشئها مدير المدرسة/المدير العام/الأستاذ ويختار الجمهور (الكل، التلاميذ، الأولياء، الأساتذة، الإدارة) والمستوى.
- يظهر لكل دور حسب ما يخصه: التلميذ يرى أحداث مستواه، الولي أحداث أبنائه، الأستاذ أحداث أقسامه.
- تبويب **التقويم المدرسي** في فضاءات المدير والتلميذ.
- جدول `CalendarEvent` جديد.

### ج) السجل الصحي للتلميذ
- الولي يعبّئ سجلًا صحيًا مبسطًا لابنه (حساسية، أمراض مزمنة، فصيلة دم، هاتف طوارئ) من تبويب **السجل الصحي**.
- يطلع عليه أستاذ القسم (تبويب **السجل الصحي**) ومدير المدرسة فقط، بسرية تامة — لا يظهر للأساتذة الآخرين.
- جدول `HealthRecord` جديد (سجل واحد لكل تلميذ).

### د) إذاعة الطوارئ
- مدير المدرسة/المدير العام يبعث **تنبيهًا عاجلًا** لكل الأولياء دفعة واحدة (تعليق دروس، حادث...) من تبويب الإشعارات.
- يصل كإشعار فوري لكل حساب ولي.
- مسار `/api/director/broadcast` جديد.

### هـ) مكتبة الموارد المشتركة بين الأساتذة
- الأستاذ ينشر موردًا تعليميًا في **المكتبة** (زر "مشاركة" في الموارد التعليمية).
- باقي الأساتذة يستفيدون منه عبر تبويب **مكتبة الموارد** مع فلاتر (مادة / مستوى / نوع).
- شارة `isShared` جديدة على جدول `TeachingResource` + مسار `/api/teacher/library`.

## المرحلة 12 — الجانب التقني (الصلاحيات واللوحة المالية)

> **ملاحظة:** اللوحة المالية الشاملة أُنجزت في المرحلة 4.3 (تبويب «اللوحة المالية» في فضاء الإدارة + تقارير PDF/CSV + تسوية + كشف شذوذ) — التفاصيل في `docs/STAGE4.3_DONE.md`.

1. **الصلاحيات**: كل المسارات الجديدة محمية بـ `requireRole` — الولي يقدّم الوثائق ويعبّئ السجل الصحي فقط، المدير يراجع ويوافق، الأستاذ يسجل الحضور ويطلع على السجل الصحي لأقسامه فقط.
2. **لوحة مالية شاملة** (المدير العام/النظامي): إيراد الشهر الحالي، مخطط الإيراد الشهري (آخر 12 شهرًا)، وتنبيه **اشتراكات على وشك الانتهاء** (15 يومًا) مع زر **تذكير بالتجديد** يبعث إشعارًا للولي.
3. **تذكير بالتجديد**: مسار `/api/admin/subscriptions/:id/remind` جديد.
4. البيانات المالية معزولة: مدير المدرسة والأستاذ لا يطلعان على الاشتراكات والمداخيل.
