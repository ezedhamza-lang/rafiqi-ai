## الأقسام

| الملف | الوظيفة |
|---|---|
| `fileserver.py` | خادم CORS محلّي على `8765` — لفرض الملفات على `input[type=file]` في MediaFire (يتجاوز حدّ 5 ميB) |
| `upload_host.py` | رفع إلى catbox (احتياطي بلا حساب) |
| `mk_pack.py` | حزمة ZIP من الكتب المنشورة + ملفّ «اقرأني.txt» |
| `mk_announce.py` | توليد نصّ إعلان الحزمة مع أزرار المشاركة |
| `peek.py` | قصّ أي منطقة في PDF لفحصها بالعين |
| `prod1_*.py` | إصلاح/تحقّق/مقارنة ترويسة كتاب الإنتاج s1 (مثال مرجعي لمحرّك هندسي) |
| `fix_level.py`, `fix_level_run.py`, `fix_level_scan.py`, `level_scan.py` | محرّك تصحيح «التعليم الأساسي» ← «الابتدائي» |
| `promote.py`, `fix_titles.py` | الترقية إلى `_FIXED` بعد الفحص، وتصحيح البيانات الوصفية |
| `posts/p1.html … p6.html` | النصّ الحرفي لكل مقال منشور |
| **`check_i18n.js`** | **حارس الترجمة — شغّله قبل أي نشر للمنصة** (التفصيل أدناه) |
| `check_i18n.selftest.mjs` | يثبت أنّ الحارس يلتقط الخلل فعلًا (يحقن مفتاحًا مكرّرًا ثم يستعيد الملف) |

## ⚠️ حارس الترجمة — لا تنشر بدونه

```bash
node tools/rafiqi-publishing/check_i18n.js
# «جاهز للنشر ✓»  → اعرض
# «مشكلة — لا تنشر» → توقّف وأصلح
```

**لماذا وُلد هذا السكربت:** في 07/10/2026 أسقط مفتاح `freeBooks` مكرّر داخل
`footer` **المنصة كلّها بيضاء**. السبب: `JSON.parse` لا يشتكِ من التكرار —
يأخذ الأخير صامتًا — فيصير `t()` يُرجع كائنًا بدل نصّ، ويرمي React
`error #31` (Objects are not valid as a React child) داخل `<h4>`، فجذر
الصفحة يبقى فارغًا.

يفحص ثلاثة أشياء:
1. **نوع** كل مفتاح مستعمل (نصّ في التذييل، كائن في الصفحة الرئيسية).
2. **تكرار** أي مفتاح داخل الفرع الواحد — ويُظهر المسار مثل `footer/freeBooks`.
3. ألّا **عاد رابط الحزمة ZIP** إلى المنصة (سياسة «التوزيع فقط»).

**قاعدة عامة:** لا تُكرّر اسم مفتاح بين قسمين، واحذف المفتاح غير المستعمل
من `ar.json` **و** `en.json` معًا.
