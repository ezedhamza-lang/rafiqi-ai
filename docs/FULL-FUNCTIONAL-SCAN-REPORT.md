## 1. ما الذي يُقاس بالضبط (تعريف PASS)

الزر لا يُعدّ ناجحًا لمجرد أن الصفحة فُتحت أو أن الطلب أعاد `200`. الشرط المُطبَّق:

```
PASS  ⇐  Click  →  handler  →  API  →  Database  →  Response  →  UI
```

لكل عنصر تفاعلي مرئي سُجِّل:
| ما يُقاس | كيف |
|---|---|
| نقرة حقيقية | `el.click()` على DOM حيّ، **بعد إعادة تحميل الصفحة** حتى لا تؤثر نقرة في التي بعدها |
| طلبات HTTP | method + path + status لكل طلب أنتجته النقرة |
| **الوصول إلى قاعدة البيانات** | **فروق عدد الصفوف في كل جدول** قبل/بعد (استعلام واحد دقيق) — لا «200» ولا «الواجهة تغيّرت» |
| تغيّر الواجهة | طول النص + المسار قبل/بعد |
| أخطاء الكونسول | `console.error` + `pageerror` |
| **بقاء الأثر** | **إعادة تحميل** بعد كل كتابة، ثم التحقق أن قاعدة البيانات لم تُعَد |

### معاني الأحكام
| الحكم | المعنى |
|---|---|
| `PASS_DB` | النقرة وصلت إلى الجدول (صفّ أُضيف/حُذف/تغيّر) |
| `PASS_REQUEST` | النقرة نفّذت كتابة(n/r) 2xx وغيّرت الواجهة |
| `PASS_REJECTED` | التحقّق رفض البيانات (4xx) ولم يُكتب شيء — سلسلة العمل سليمة |
| `PASS_NAV` / `PASS_UI` | عنصر تنقّل / عنصر واجهة بحت |
| `PASS_RELOAD` | الأثر بقي بعد إعادة التحميل |
| `FAIL_DEAD_CONTROL` | النقرة لم تفعل شيئًا: لا طلب ولا تغيير — **زر ميت** |
| `FAIL_NOT_CLICKABLE` | لم يوجد عند لحظة النقر (لrace في القياس) |
| `FAIL_CONSOLE` | رماى استثناء في الكونسول |
| `FAIL_API_5xx` | خطأ خادم |
| `BLOCKED_RATE_LIMIT` | مُنعت بسبب حدّ المعدّل (مرتبط بـISS-020) |
| `NOT_EXECUTED` | لم يُنفَّذ عمدًا مع سبب مكتوب |
