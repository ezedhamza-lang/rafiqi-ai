## 1. ✅ Prisma/قاعدة البيانات

**المشكلة المبلّغة:** `npx prisma generate` يفشل بلا شبكة؛ التسليم المبني في بيئة Windows بلا إنترنت.

**التحقق الفعلي (هذه البيئة — شبكة متاحة):**
- `npx prisma generate` → ناجح.
- `npx prisma migrate deploy` → 9 هجرات مطبّقة.
- `node prisma/seed.js` → 6 حسابات تجريبية مبذورة.

**الخلاصة:** لا خلل في المشروع؛ الشرط الوحيد هو بيئة ذات شبكة لتحميل `@prisma/client`/engines.
**بنية البيانات:** PostgreSQL فقط عبر Prisma (`school_platform` + `school_platform_test`)؛ لا `school.db`.

## 2. ✅ المرحلة 6.1 — قالب الدرس الموحّد + العرض العام

**المشكلة:** المحتوى المصلّح (رياضيات + أنيسي س1) موجود في الخادم لكن الواجهة (`BookViewer`) تعرض صور صفحات ممسوحة فقط — **المحتوى لا يصل للتلميذ**.

**الحل (مشارك مع الإصلاح #2):**
- `frontend/src/components/LessonViewer.jsx` (جديد): مكوّن عرض دروس موحّد يعرض البلوكات:
  `objective` (الأهداف) / `concept` (المفهوم) / `definition` (التعريف) / `example` (أمثلة) /
  `note` (ملاحظة) / `question` (تمارين MCQ قابلة للتحقق + إظهار الإجابة).
  + قراءة صوتية (SpeechSynthesis بالعربية) + تنقّل بين الدروس + قائمة دروس جانبية (RTL).
- `frontend/src/pages/student/StudentBooks.jsx`: زر «الدروس التفاعلية» يفتح `LessonViewer`؛
  زر ثانوي «تصفّح الكتاب» يبقي الصور الممسوحة متاحة.
- `backend/tests/curriculum.test.js` (جديد): 5 اختبارات تثبت أن محتوى س1 يصل للتلميذ عبر الـ API
  (كتب كاملة، دروس رياضيات/أنيسي، بلا دروس غير جاهزة، كل أنواع الكتل مدعومة).

**نتيجة حيّة:** `GET /api/public/curriculum/books/year1/math/lessons` → 26 درساً،
الدرس الأول يحوي objective/concept/definition/4×example/note بمحتوى كامل.
