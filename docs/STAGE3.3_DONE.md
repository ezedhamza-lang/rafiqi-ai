# المرحلة 3.3 — المحادثة الفورية (ولي ↔ أستاذ) (منجزة)

تاريخ الإنجاز: 14-08-2026
النطاق: الدفعة 3.3 من المرحلة 3 — تواصل مباشر ولحظي بين الولي والأستاذ داخل المنصة عبر WebSocket، مع إشعار فوري عند وصول رسالة (شارة عدّاد في الهيدر) وحفظ سجل المحادثات في قاعدة البيانات.
المرجع: `docs/PHASES_SPLIT.md` — الدفعة 3.3.

## ما تم إنجازه

### 1. سياسة مراسلة جديدة (ولي ↔ أستاذ)
- ملف جديد `backend/src/services/messagingPolicy.js` يوحّد سياسة المراسلة بين REST و WebSocket:
  - `MESSAGE_POLICY` — **الولي** يخاطب: معلمي أبنائه + مدير المدرسة + الإدارة العامة. **الأستاذ** يخاطب: أولياء تلاميذه + مدير المدرسة + الإدارة العامة (الأدوار الأخرى كما كانت).
  - `isAllowedContact(sender, recipient)` — قيد النطاق بأقل صلاحية: الولي لا يراسل إلا معلمي أبناء أقسام أبنائه، والأستاذ لا يراسل إلا أولياء تلاميذ أقسامه.
  - `scopedRecipientIds(user)` — قائمة معرفات جهات الاتصال المقيدة لاستعمالها في مسار المستلمين.
- `GET /api/messages/recipients` — أصبح **مقيّداً بالنطاق**: الولي يرى معلمي أبنائه فقط (+ الإدارة)، والأستاذ يرى أولياء تلاميذه فقط (+ الإدارة).

### 2. المحادثة اللحظية عبر `/ws` (نفس البنية الموجودة)
- `backend/src/ws.js` — توسعة خادم WebSocket الموجود:
  - `message:send` — استقبال رسالة لحظية، التحقق من صلاحية المرسل/المستقبل، حفظها في قاعدة البيانات، وبثها للمستقبل فوراً (`message:new`) + تحديث عدّاده (`unread`).
  - `message:read` — تعليم رسائل الطرف المقابل كمقروءة، بث إشارة قراءة للمرسل، وتحديث العدّادات.
  - `typing` — بث حدث الكتابة (موجود سابقاً، محتفظ به).
  - تصدير `sendToUser` و `broadcastUnread` لإعادة الاستعمال من مسارات REST.
- `POST /api/messages/messages` (REST) — أصبح يبث `message:new` + `unread` لحظياً للمستلم، و `GET /api/messages/messages/:userId` يبث `message:read` للطرف الآخر عند فتح المحادثة.
- سجل المحادثات محفوظ في نموذج `Message` الموجود (بدون تغيير في المخطط).

### 3. الواجهة الأمامية (React)
- ملف جديد `frontend/src/context/ChatContext.jsx` + `ChatProvider`:
  - اتصال WebSocket تلقائي بـ `/ws?token=...` عند دخول مستخدم (غير تلميذ) مع إعادة اتصال تلقائية بمهلة تراجعية.
  - حالة `unread` لحظية تُحدَّث من أحداث الخادم، ودالة `sendEvent` لأحداث الكتابة/القراءة، ودالة `subscribe` للأحداث.
- `frontend/src/components/Header.jsx`:
  - شارة عدّاد الرسائل غير المقروءة **لحظية** عبر السياق (بدل الاستطلاع كل 30 ثانية) + مؤشر نقطة خضراء نابضة تدل على اتصال المحادثة الفورية.
- `frontend/src/pages/Messages.jsx`:
  - وصول لحظي للرسائل الجديدة: تُضاف فوراً داخل المحادثة المفتوحة أو تُحدَّث قائمة المحادثات.
  - بث حدث «يكتب الآن» أثناء الكتابة مع مؤشر كتابة، وبث تعليم القراءة عند فتح المحادثة/استلام رسالة.
  - إيصالات قراءة (علامة ✓ / ✓✓) على الرسائل المرسلة عند قراءتها.
  - عرض رسالة الخطأ القادمة عبر WebSocket (صلاحية غير كافية) إن وقعت.
- تظليل: `frontend/src/index.css` — أنماط `nav-live` (مؤشر الاتصال) و `chat-receipt` (إيصال القراءة).

### 4. اختبارات
- `backend/tests/messages.test.js` — 10 اختبارات:
  - السماح للولي بمراسلة معلم ابنه (REST) وللأستاذ بمراسلة ولي تلميذه.
  - رفض الولي مراسلة أستاذ ليس معلم ابنه، ورفض الأستاذ مراسلة ولي غريب (403).
  - بث REST → استقبال الأستاذ لحظياً عبر WebSocket.
  - إرسال عبر WebSocket → استقبال الولي لحظياً + حفظ في قاعدة البيانات + عدّاد غير المقروء.
  - بث `typing`.
  - فتح الولي للمحادثة → إشارة `message:read` للأستاذ + تصفير العدّاد.
  - نطاق المستلمين: الولي يرى معلم ابنه فقط، والأستاذ يرى ولي تلميذه فقط.
