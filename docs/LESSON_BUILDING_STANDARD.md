# قاعدة بناء الدروس — الهوية التربوية والبصرية الموحّدة (ذاكرة المشروع)

> **جملة التشغيل:** عندما يقول المستخدم «اتبع التمشي الصحيح في بناء الدروس» أو «طبّق التمشي» → طبّق هذه القاعدة كاملة دون إعادة شرح.
> هذه قاعدة أساسية ثابتة لجميع الكتب والمواد داخل المشروع.

## المبدأ العام
تُطبَّق **نفس فلسفة بناء الدروس على جميع المواد** مع تكييف نوع الأنشطة/الأسئلة حسب طبيعة المادة.
**هوية تربوية وبصرية موحّدة** لكل الكتب (نفس تصميم البطاقات، أسلوب العناوين، عرض التعليمات، أسلوب الرسوم، ترتيب الصفحات، وأسلوب التقويم) — ويختلف **نوع** التمارين حسب المادة فقط.

**قاعدة مرفوضة:** لا يُقبل درسٌ = «شرح قصير + أسئلة قليلة + خلاصة».
**المطلوب:** وحدة تعليمية كاملة تُدرّب التلميذ تدريجيًا حتى مستوى الاختبار.

**الهيكل العام الموحّد:** سند واضح → اكتشاف/ملاحظة → فهم → أمثلة موجّهة → تمارين متدرّجة → تمارين متنوعة وكثيفة → وضعيات/تطبيق → تدريب شبيه بالاختبار → تقويم.

**المحتوى القديم يُعاد بناؤه بالكامل، مع الاحتفاظ بعناوين الدروس (والمعرّفات/المرجع الرسمي) فقط.**

---

## الرياضيات
وضعية/صورة/سند → ملاحظة واكتشاف → فهم المفهوم → أمثلة موجّهة → تمارين متدرّجة → تمارين متنوعة → وضعيات مشكلة → تطبيق → تدريب شبيه بالاختبار → تقويم.
أنشطة: أكمل · أحسب · أربط · أضع العدد في المكان المناسب · أختار · ✓/× · ألوّن · أرتّب · أقارن (>,<,=) · أضع الأعداد في جدول · أمثّل برسوم/مكعبات/أشكال · أكتشف الخطأ وأصحّحه · أحل وضعية مشكلة · أفسّر طريقة الحل.

## العربية والقراءة
نص/صورة → ملاحظة وفهم → أسئلة مباشرة → أسئلة استنتاجية → مفردات → تراكيب/لغة → تمارين متنوعة → إنتاج/توظيف → تقويم.

## الإيقاظ العلمي
سند/صورة/تجربة → ألاحظ → أصف → أقارن → أصنّف → أستنتج → أفسّر → أوظّف → أقوّم.

## بقية المواد
نفس الفلسفة العامة: سند واضح + اكتشاف + أسئلة متدرّجة ومتسلسلة + تمارين متنوعة وكثيفة + تطبيق + تقويم نهائي.

## قواعد تقنية ثابتة (تنفيذ)
- **الصورة أولاً/السند أولاً:** يبدأ الدرس بسند (وضعية/نص/صورة كبيرة) تُبنى **كل** الأسئلة عليه (مسترسلة)، وتنوَّع الأنواع كورقة الامتحان.
- **لا صوت ولا قراءة آلية في الدروس/الكتب** (أُزيلت أزرار الاستماع من عارض الدروس).
- **الصور:** أسلوب موحّد: `flat vector children-book illustration, soft pastel palette, rounded shapes, thick clean outlines, warm light, white background, no text, no letters, no watermark, 4:3`.
- تُخزَّن في `frontend/public/curriculum/<year>/<subject>/` وتُخدم من `/curriculum/<year>/<subject>/...` (لا `backend/uploads` فهو مُستثنى من Docker).
- تُكتب داخل `backend/curriculum/<year>/<subject>-units.json`؛ رياضيات س1 ببنية `studentBlocks` (أنواع: concept/question/picture-choice/math-input/textarea/drawing/match-pairs/summary).
