**السبب الجذري (مثبت بسطر واحد):** `curriculumService.js:133` يحسب `lessonsCount` بعدّ المفاتيح **المستوى الأعلى** التي تحمل `title` فقط:
```js
lessonsCount = Object.entries(ldata).filter(([k, v]) => k !== '_meta' && v && v.title).length;
```
لكنّ صيغة الملفات بصيغة متداخلة (مصفوفة داخل كائن):
- `reading-units.json` = `{_meta, title, units:[…]}` ← المفتاح `units` مصفوفة بلا `title` ⇒ **0**

- `production-units.json` (سن2-6) بالشكل نفسه ⇒ **0**
- `year2/science` و`year3/science`: **لا `lessonsFile` أصلًا في السجل** ⇒ العدّاد لا يعمل ⇒ 0

والواجهة تُخفي الزر عند `lessonsCount === 0` (`StudentBooks.jsx:150`)، و`hasImages` لهذه الكتب = `false` ⇒ **الزر الثاني مخفي أيضًا** ⇒ بطاقة بلا أي طريق.
