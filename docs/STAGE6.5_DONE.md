# المرحلة 6.5 — تعلم تكيفي أولي (تكرار متباعد + مستوى ديناميكي)

تاريخ الإتمام: 17-08-2026
الحالة: **مكتملة** — محرك تكرار متباعد (SM-2) يُصعّب/يُسهّل مستوى السؤال حسب أداء التلميذ، مع استمرار دائم وواجهة «مراجعة ذكية» في فضاء التلميذ.

---

## قرار النطاق

الدفعة 6.5 (`docs/PHASES_SPLIT.md`) تنص على:
«تصعيب/تسهيل الأسئلة حسب الأداء (Spaced Repetition). قبول: مستوى السؤال يتغير حسب إجابات التلميذ.»

بموجب قاعدة المشروع «**لا نختلق محتوى**» (نفس نهج 6.2/6.3/6.4)، بُني المحرك التكيفي فوق **البنوك الحقيقية الموجودة** (قوالب + بنك الأسئلة عبر نقطة نهاية التمارين):

- **لا ميتاداتا صعوبة مختلقة** — لا تُضاف درجات صعوبة يدوية لأي سؤال في البنوك.
- **المستوى يتولّد من أداء التلميذ نفسه**: سلسلة إجابات صحيحة تصعّب السؤال (مستوى 1←5)، وكل خطأ يُسهّله (يعود للأدنى).
- **التكرار المتباعد** (SM-2) يحدّد موعد إعادة عرض كل بطاقة: فاصل يوم ← 6 أيام ← يتضاعف بعامل السهولة، ويُصفَّر عند الخطأ.
- كل ذلك يُحفظ في قاعدة البيانات لكل تلميذ، فيبقى التقدّم عبر الجلسات (يعود التلميذ غداً فيجد بطاقاته المستحقة).

## ما أُنجز

### 1. نموذج البيانات — `AdaptiveCard` (هجرة `20260817100000_adaptive_learning`)

| الحقل | الوصف |
|---|---|
| `userId` / `itemKey` | التلميذ + مفتاح بطاقة ثابت `exerciseId:questionIndex` (فريد مركّب) |
| `gradeId` / `subjectId` | الكتاب الذي تُمارس فيه البطاقة |
| `repetitions` / `easeFactor` / `intervalDays` / `dueAt` | حالة SM-2 (التكرار، السهولة، الفاصل، الموعد) |
| `difficulty` (1..5) | مستوى السؤال الديناميكي المشتق من الأداء |
| `reviewCount` / `correctCount` / `streak` / `lastQuality` | سجل المراجعات والمستجدات |

### 2. الخدمة — `backend/src/services/adaptiveService.js`

- `sm2Next(state, quality)`: خوارزمية SM-2 (فاصل 1←6←×EF، حد أدنى للسهولة 1.3، صفر عند الخطأ).
- `difficultyFromState({streak})`: المستوى = 1 + سلسلة النجاحات المتتالية (مقصوصة على 5) — يتغير فوراً مع كل إجابة.
- `buildSession(userId, gradeId, subjectId, limit)`: صفّ المراجعة — **المستحقة أولاً** (حسب `dueAt`)، ثم بطاقات جديدة من البنك؛ يُنشئ سجلات البطاقات الجديدة.
- `applyReview(...)`: تسجيل إجابة → تحديث حالة SM-2 والمستوى، ويعيد الحالة الجديدة والموعد القادم.
- `summarize(...)`: إجمالي البطاقات، المستحقة الآن، المتقنة، الدقة، توزيع المستويات 1-5.

### 3. نقاط نهاية API (`/api/student` — مصادقة تلميذ)

- `GET /api/student/adaptive/session?gradeId&subjectId&limit` — جلسة مراجعة (سؤال + حالة تكيفية لكل بطاقة).
- `POST /api/student/adaptive/review` — `{ itemKey, gradeId, subjectId, quality(0-5) | correct }` → الحالة الجديدة.
- `GET /api/student/adaptive/summary?gradeId&subjectId` — ملخص التقدم (بدون فلاتر يعطي كل الكتب).

### 4. واجهة المستخدم

- **`frontend/src/pages/student/StudentAdaptive.jsx`** (جديد): صفحة «المراجعة الذكية» —
  فلاتر مادة × مستوى، بطاقات إحصائية (مستحق اليوم/مُتتبَّع/متقن/دقة)، أشرطة توزيع المستويات،
  بطاقة سؤال بعلامة المستوى (نجوم 1-5) وخيارات/إدخال نص، تحقّق فوري يرسل المراجعة
  ويعرض «المستوى الجديد + موعد المراجعة القادم»، وتحميل متتابع لباقي الجلسة.
- **`frontend/src/pages/student/StudentSpace.jsx`**: تبويب «مراجعة ذكية» (أيقونة `psychology`) + مسار `adaptive`.
- **`frontend/src/index.css`**: أنماط جديدة (ملخص، نجوم المستويات، بطاقة الجلسة، التغذية الراجعة).
