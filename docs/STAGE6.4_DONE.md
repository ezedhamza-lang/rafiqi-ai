# المرحلة 6.4 — فيديوهات قصيرة (كتالوج مصادر خارجية)

تاريخ الإتمام: 17-08-2026
الحالة: **مكتملة (بنية الكتالوج + المشغّل)** — كتالوج فيديوهات قصيرة بميتاداتا موحّدة، مشغّل يدعم مصادر خارجية معتمدة (يوتيوب/Dailymotion/Vimeo/ملفات مباشرة)، وواجهات تلميذ: تبويب «فيديوهات» في عارض الدروس + صفحة «الفيديوهات» في فضاء التلميذ.

---

## قرار النطاق

الدفعة 6.4 (`docs/PHASES_SPLIT.md`) تنص على: «فيديوهات 3-5 دقائق لكل درس (تقديري). قبول: فيديو لكل درس نموذجي.»

بموجب قاعدة المشروع «**لا نختلق محتوى**»، وبقرار المستخدم، بُنيت **بنية كتالوج الفيديوهات القصيرة** بدل إنتاج محتوى فيديو مختلق:

- لا توجد ملفات فيديو في الأرشيف، ولا يمكن توليد فيديوهات دروس حقيقية في بيئة التنفيذ.
- **الكتالوج فارغ حاليًا عمدًا** — يُملأ لاحقًا حصريًا من **مصادر خارجية حقيقية معتمدة** (قنوات/جهات رسمية أو معتمدة) بعد مراجعة بشرية، بما يتوافق مع «لا نختلق محتوى» (نفس نهج 6.2 و6.3: «تجهيز الشكل»).
- البنية كاملة وجاهزة: إضافة أي فيديو معتمد للكتالوج يظهر فورًا في عارض الدروس وصفحة الفيديوهات دون أي تعديل في الكود.

## ما أُنجز

### 1. ملف الكتالوج — `backend/content/videos/video-catalog.json`

بنية موثّقة في `_meta` (الحقول + القواعد) مع قائمة `videos` **فارغة**:

| الحقل | الوصف |
|---|---|
| `id` | معرّف فريد |
| `title` / `description` | العنوان والوصف |
| `provider` | `youtube` \| `dailymotion` \| `vimeo` \| `direct` |
| `videoId` | معرّف الفيديو عند المزوّد (للمزوّدين المدمجين) |
| `url` | رابط مباشر https للملف (للمزوّد `direct` فقط) |
| `durationSeconds` | المدة بالثواني (تُعرض كـ 3-5 دقائق) |
| `thumbnail` | رابط صورة مصغّرة https (اختياري) |
| `source` | اسم المصدر الحقيقي |
| `gradeId` / `subjectId` / `unitId` / `lessonId` | الربط بالسنة/المادة/الوحدة/الدرس |
| `status` | `active` |

**قواعد إلزامية**: روابط **https فقط** (لا http)، مزوّدات ضمن القائمة فقط، `videoId` إلزامي للمزوّدين المدمجين و`url` لملف مباشر.

### 2. الخدمة — `backend/src/services/videoCatalogService.js`

- `validateVideoEntry(entry)`: تحقق صارم (https فقط، مزوّدات مسموحة، videoId/url، مدة غير سالبة، صورة https).
- `buildEmbedUrl(entry)`: بناء رابط تضمين https لكل مزوّد (يوتيوب عبر `youtube-nocookie` لحماية الخصوصية).
- `buildThumbnail(entry)`: اشتقاق مصغّرة من المزوّد عند غيابها (يوتيوب/Dailymotion).
- `formatDuration(seconds)`: «4 دقيقة» / «1 س و 1 د».
- `toPublicVideo(entry)`: الشكل العمومي الآمن للتلميذ — **لا يُنتج عنصرًا بلا رابط قابل للتضمين**.
- `listVideos({gradeId, subjectId, unitId})` / `getVideo(id)`: فلترة ببقاء الفيديوهات العامة، مع قبول كتالوج اختباري (لاختبارات بدون ملفات).

### 3. نقاط نهاية API (عمومية — `backend/src/routes/curriculum.js`)

- `GET /api/public/videos` — كتالوج الفيديوهات مع فلاتر `gradeId`/`subjectId`/`unitId`.
- `GET /api/public/videos/:id` — تفاصيل فيديو واحد (404 إن غاب).
- `GET /api/public/curriculum/books/:gradeId/:subjectId/videos` — فيديوهات كتاب (مرتبطة بمادته وسنته).

### 4. واجهات المستخدم

- **`frontend/src/components/VideoPlayer.jsx`** (جديد): مشغّل يعرض التضمين المدمج (iframe آمن: `title`, `referrerPolicy`, `allowfullscreen`) أو ملف مباشر (`<video controls>`)، مع حالات تحميل وخطأ.
- **`frontend/src/components/VideoCard.jsx`** (جديد): بطاقة فيديو (مصغّرة + زر تشغيل + المدة + العنوان + المصدر + المزوّد).
- **`frontend/src/components/LessonViewer.jsx`**: تبويب ثالث «فيديوهات» لكتاب (يُحمّل عبر نقطة نهاية الكتاب)، والفيديو المرتبط بدرس (`lessonId`/`unitId` مطابق) يظهر داخل صفحة الدرس كـ «فيديو قصير لهذا الدرس».
- **`frontend/src/pages/student/StudentVideos.jsx`** (جديد): صفحة «الفيديوهات» في فضاء التلميذ مع فلاتر (مادة × مستوى) ومشغّل.
- **`frontend/src/pages/student/StudentSpace.jsx`**: تبويب «الفيديوهات» مع أيقونة `smart_display`.
- **`frontend/src/index.css`**: أنماط البطاقات والمشغّل والنوافذ المنبثقة (متجاوبة).

## اختبارات جديدة (12) في `backend/tests/videos.test.js`

1. ملف الكتالوج موجود وصالح JSON ببنية `videos`.
2. التحقق يقبل عنصرًا صالحًا لكل المزوّدين الأربعة.
3. رفض المزوّد غير المدعوم.
4. رفض رابط http غير آمن.
5. رفض الملفات غير المباشرة لـ `direct`.
6. رفض نقص `videoId` للمزوّدات المدمجة.
7. رفض المدة السالبة والصورة غير https.
8. بناء روابط التضمين الصحيحة لكل المزوّدين (https).
9. اشتقاق المصغّرات + `toPublicVideo` لا يُنتج عنصرًا بلا رابط.
10. `formatDuration` (دقائق/ساعات/قيم صفرية/غير رقمية).
11. الفلترة تُبقي الفيديوهات العامة و`getVideo` يعيد عنصرًا أو null (كتالوج اختباري).
12. نقاط النهاية: قائمة `[]`، فلترة، 404، فيديوهات كتاب `[]` بحالة 200.

## ما لم يُنجز (مُرجأ حتى تُوفَّر مصادر)

- **محتوى الفيديوهات نفسه** — يُملأ الكتالوج من مصادر خارجية حقيقية معتمدة (مراجعة بشرية إلزامية قبل النشر، كما في 6.2/6.3).
- تعدد السنوات/المواد في البنك — يتبع توفر المصادر المعتمدة لكل سنة/مادة (البنية جاهزة للتمديد بأي عدد من العناصر).
