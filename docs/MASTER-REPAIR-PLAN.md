### ISS-003: شهادات PDF العربية (WinAnsi)
- **السبب الجذري**: مكتبة PDF بترميز WinAnsi (مثبت: `cannot encode 0x0631` في `certificateService.js:61`).
- **الإصلاح**:

  2. تضمين خط TTF عربي (Amiri/Cairo — تحقق الرخصة) وتسجيله `.font()` قبل أي نص عربي.
  3. اختبار توليد AR + FR.
- **الاختبار**: الشهادتان → ‏200 + `application/pdf` + رأس `%PDF` + عدم وجود exception في السجل.
- **الارتداد**: مسارات PDF الأخرى (bulletin/invoice/memo-DOCX) — قراءة كود فقط (مسارات منفصلة).
- **الخطر**: متوسط (ملف خط ~1MB في المستودع — مقبول).

### ISS-009: سجل الدرجات فارغ (خلط الهويات)
