## ما تم إنجازه

### 1. واجهة مزوّد فيديو تجريدية قابلة للتبديل
- `backend/src/services/videoProvider/index.js` — اختيار المزوّد حسب `VIDEO_PROVIDER`:
  - **LOCAL** (الافتراضي): بث تجريبي داخلي بلا أي خدمة خارجية — غرفة انتظار للتلميذ/الولي حتى يبدأ الأستاذ، مع توليد تسجيل WAV تجريبي (5–60 ثانية) تلقائياً عند إنهاء الحصة.
  - **LIVEKIT**: بث حقيقي متعدد الأطراف — يوقّع توكنات JWT (HS256) للغرفة، `canPublish` للأستاذ فقط.
- `local.js` / `livekit.js` / `wav.js` — تطبيقات المزوّدين ومولّد الموجة التجريبية.
- الإعدادات كلها من `.env` (`VIDEO_PROVIDER`, `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`, `RECORDING_DIR`) عبر `src/config.js` بلوك `video`.

### 2. نموذجا بيانات جديدان (تهجير `20260815090715_live_sessions`)
- `LiveSession` — الحصة: الأستاذ (علاقة `LiveSessionTeacher`)، القسم، العنوان، المادة، الوصف، المزوّد، اسم الغرفة الفريد (`roomName`)، موعدا البداية والنهاية، الحالة (`SCHEDULED`/`LIVE`/`ENDED`/`CANCELLED`)، عدد أقصى للمشاركين.
- `LiveRecording` — التسجيل: الحصة، مسار/رابط الملف، الحالة (`PENDING`/`AVAILABLE`/`FAILED`)، المدة، الحجم، تاريخ الإتاحة.

### 3. منطق الحصص (`src/services/liveSessionService.js`)
- `sanitizeRoomName` — يولّد slugs فريدة من العنوان + طابع زمني لمنع تعارض أسماء الغرف.
- `classStudentAndParentIds` — استخراج تلاميذ/أولياء القسم للإشعارات والأذونات.
- `reconcileSession` — تصفية الحصص حسب الدور: الأستاذ يرى حصصه فقط، التلميذ/الولي حصص قسمهم (+ العامة `classId: null`)، الإداريون كل الحصص.
- `finalizeSession` — عند الإنهاء: توليد التسجيل عبر المزوّد، حفظ `LiveRecording`، وإرسال إشعارات للتلاميذ والأولياء بتوفّر التسجيل (`services/notify.js`).
- الحالات تُحدَّث تلقائياً: حصص `SCHEDULED` تتجاوز نهايتها ← `ENDED`؛ حصص مجدولة حان موعدها أثناء الفحص ← تُعرض كقابلة للانضمام.

### 4. واجهة API (`src/routes/liveSessions.js` + `src/validators/liveSessions.js`)
| المسار | الوظيفة |
|---|---|
| `GET /api/live/config` | معلومات المزوّد الحالي للواجهة (تجريبي/حقيقي + دعم التسجيل) |
| `GET /api/{teacher|student|parent}/live` | قائمة الحصص حسب الدور (تلميذ/ولي: قسمهم فقط) |
| `GET /api/{teacher|student|parent}/live/recordings` | التسجيلات المتاحة للتحميل/المعاينة |
| `POST /api/teacher/live` | جدولة حصة جديدة (تحقق Zod: عنوان، مادة، قسم، مواعيد) |
| `PUT /api/teacher/live/:id` | تعديل حصة مجدولة (حجز الأستاذ فقط) |
| `POST /api/teacher/live/:id/start` | بدء الحصة (الأستاذ/الإداريون) — يصدر توكن انضمام بنشر |
| `POST /api/{teacher|student|parent}/live/:id/join` | انضمام — رفض قبل بدء الحصة (403) وحسب الدور |
| `POST /api/teacher/live/:id/end` | إنهاء الحصة ← تسجيل تلقائي + إشعارات |
| `POST /api/teacher/live/:id/cancel` | إلغاء حصة مجدولة |
| `GET /api/{teacher|student|parent}/live/:id/recording` | تحميل التسجيل (بث الملف) |

- كل المسارات محمية بالمصادقة والأدوار (`authMiddleware` + `requireRole`)، والأخطاء برسائل عربية عبر `middleware/messages.js`.
- التوثيق أُضيف في `src/swagger.js` (tag `live-sessions`).

### 5. حضور فوري عبر WebSocket (`src/ws.js`)
- رسالة `live:presence` (`join`/`leave`) مع `handleLivePresence` و`livePresence` Map — بث قائمة الحضور اللحظية لكل عملاء الغرفة.

### 6. الواجهة الأمامية (React)
- مكوّن `frontend/src/components/LiveRoom.jsx` — غرفة حية موحّدة للدورين:
  - **LOCAL**: شاشة انتظار للتلميذ/الولي حتى بدء البث؛ عند بدئه تظهر قائمة الحضور الحية عبر WS.
  - **LIVEKIT**: يتصل تلقائياً (حمل ديناميكي لـ `livekit-client`) — كاميرا/ميكروفون الأستاذ تنشر، التلاميذ يتابعون فقط.
- صفحات جديدة:
  - `teacher/LiveSessions.jsx` — جدولة/إدارة/بدء/إنهاء/إلغاء حصص الأستاذ + معاينة وتحميل تسجيلاته.
  - `student/StudentLiveSessions.jsx` و`parent/ParentLiveSessions.jsx` — حصص القسم + التسجيلات المتاحة (تشغيل/تحميل).
- ربط المسارات والتبويبات: `TeacherDashboard.jsx` (`/teacher/live`)، `StudentSpace.jsx` و`ParentSpace.jsx` (تبويب «حصصي المباشرة» + مسار `/student/live` و`/parent/live`)، و`Header.jsx` (قائمتا الأستاذ والولي).
- أنماط جديدة في `frontend/src/styles/components.css` (`.live-room-grid`, `.live-stage`, `.live-tracks`, `.live-participant`, `.live-members`, ...).

### 7. الاختبارات
- `backend/tests/live-sessions.test.js` — **16 اختباراً جديداً**:
  - حماية الوصول: تلميذ/ولي ← 403 على جدولة/إدارة؛ أستاذ لا يمسّ حصة غيره.
  - الجدولة (نموذج بيانات صحيح + رفض نقص العنوان/المادة/المواعيد).
  - تحديث حصة مجدولة، وإلغاؤها.
  - دورة كاملة: بدء ← انضمام تلميذ (قبل البدء 403) ← قائمة حسب الدور ← إنهاء ← تسجيل WAV فعلي.
  - تحميل التسجيل (بث ملف صالح) وقائمة التسجيلات.
  - توليد اسم غرفة فريد.

## كيف تجرّب المرحلة 5.1 (وضع الاختبار)
1. سجّل الدخول كأستاذ: `teacher@test.tn / <كلمة-السر-تجريبية>`.
2. افتح **«حصصي المباشرة»** من فضاء الأستاذ (`/teacher/live`) وجدول حصة لقسمك.
3. اضغط **«بدء الحصة»** — الحالة تصير «حية الآن» وتظهر للتلميذ/الولي.
4. سجّل الدخول كتلميذ `student@test.tn / <كلمة-السر-تجريبية>` أو ولي `parent@test.tn / <كلمة-السر-تجريبية>`، افتح تبويب «حصصي المباشرة» وانضم — ستجد شاشة الانتظار وقائمة الحضور الحية.
5. عد للأستاذ واضغط **«إنهاء الحصة»** — يظهر تسجيل تجريبي، ثم حمّله/شغّله من قائمة التسجيلات.
6. للبث الحقيقي: اضبط `VIDEO_PROVIDER=LIVEKIT` + بيانات LiveKit في `.env` (التوكنات تُوقَّع محلياً).
