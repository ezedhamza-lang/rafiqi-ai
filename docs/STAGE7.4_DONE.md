# المرحلة 7.3+ — إشعارات استباقية للولي + إدارة مفتاح الذكاء الاصطناعي للمنصة

تاريخ الإتمام: 17-08-2026
الحالة: **مكتملة** — إشعار استباقي عند ارتفاع خطر التعثر + واجهة إدارية لمفتاح المنصة.

---

## النطاق

بعد المرحلة 7.3 (رؤى الولي الذكية + محرك توقع التعثر)، أُنجز بندان:

1. **إشعارات استباقية للولي**: مسح دوري يفحص أبناء الأولياء عبر `computeRisk`
   ويرسل إشعاراً داخل المنصة (مع احترام قنوات المستخدم عبر `notify`) عندما
   يرتفع خطر التعثر إلى **HIGH/CRITICAL**، مع رابط مباشر لصفحة «الرؤى الذكية».
2. **واجهة إدارية لمفتاح Gemini على مستوى المنصة**: تبويب جديد في لوحة الإدارة
   لحفظ/حذف مفتاح المنصة، يُستعمل كاحتياط عندما لا يملك المعلّم مفتاحاً خاصاً.

بموجب قاعدة **«لا نختلق محتوى»** لا يُمرَّر للذكاء الاصطناعي إلا أرقام المنصة
الحقيقية، والمفتاح يُشفَّر في قاعدة البيانات ولا يُعرض مجدداً.

## ما أُنجز

### 1. نموذج `SystemSetting` — `backend/prisma/schema.prisma`

جدول `key/value/updatedBy/updatedAt` لتخزين إعدادات المنصة (مفتاح الذكاء
الاصطناعي حالياً). هجرة `20260817120000_system_settings`.

### 2. إدارة مفتاح المنصة — `backend/src/services/aiService.js`

- `getPlatformAiKey()` / `savePlatformAiKey(adminId, apiKey)` / `deletePlatformAiKey()`.
- المفتاح يُشفَّر بنفس آلية AES-256-GCM الحالية، و`updatedBy` يسجل المسؤول.
- `resolveApiKey(teacherId)` — **ترتيب الاحتياط**: مفتاح المعلّم ← مفتاح المنصة ←
  متغير البيئة `GEMINI_API_KEY`. تستعمله `generateText` وكل دوال الذكاء الاصطناعي.

### 3. مسارات إدارية — `backend/src/routes/adminAiKey.js` (جديدة)

| المسار | الدور | الوصف |
|--------|-------|--------|
| `GET /api/admin/ai/key` | ADMIN/SCHOOL_DIRECTOR/SUPER_ADMIN | حالة المفتاح والمصدر (لا يعرض القيمة أبداً) |
| `POST /api/admin/ai/key` | نفسه | حفظ مفتاح جديد (التحقق عبر `aiKeySchema`) |
| `DELETE /api/admin/ai/key` | نفسه | حذف مفتاح المنصة |

### 4. الإشعارات الاستباقية — `backend/src/services/parentInsightNotifyService.js` (جديدة)

- `runParentInsightSweep()`: يفحص كل تلميذ مرتبط بولي، يبني بياناته الحقيقية،
  ويشغّل `computeRisk`. عند **HIGH/CRITICAL** يرسل إشعار `PARENT_RISK_ALERT`
  عبر `notify` (قناة IN_APP دائماً + احترام تفضيلات PUSH/EMAIL/SMS) مع:
  - عنوان باسم التلميذ ودرجة الخطر.
  - `link: /parent/insights` للانتقال لصفحة الرؤى.
  - `metadata` (studentId، الاسم، مستوى الخطر، الدرجة) للتفكيك.
- **منع التكرار**: `cooldownDays` (افتراضي 7) + إشعار فوري عند **تصعيد** المستوى
  (مثلاً MEDIUM→HIGH) مهما كانت المهلة.
- `startParentInsightScheduler()`: جدولة دورية كل 12 ساعة
  (يضبطها `INSIGHT_SWEEP_INTERVAL_MS`) + تشغيل أولي عند الإقلاع.

### 5. مسار تشغيل يدوي — `backend/src/routes/adminInsights.js` (جديدة)

| المسار | الدور | الوصف |
|--------|-------|--------|
| `POST /api/admin/insights/sweep` | ADMIN/SCHOOL_DIRECTOR/SUPER_ADMIN | تشغيل المسح فوراً ويعيد `{checked, alerted}` |

### 6. الواجهة — `frontend/src/pages/Admin.jsx` + `frontend/src/pages/AdminAiKey.jsx` (جديد)

- تبويبان في لوحة الإدارة: «طلبات المساعدة» و«إعدادات الذكاء الاصطناعي».
- صفحة ضبط المفتاح: حالة مهيأ/غير مهيأ + المصدر، حقل حفظ (كلمة مرور)، حذف،
  ورسالة تأكيد. المفتاح يُشفَّر ولا يُعرض.

### 7. الاختبارات (15 اختباراً جديداً)

| الملف | المضمون |
|-------|---------|
| `tests/admin-ai-key.test.js` (8) | صلاحيات، حالة غير مهيأة، رفض الفارغ، حفظ/حذف، التشفير، ترتيب الاحتياط (مفتاح المعلّم قبل المنصة) |
| `tests/parent-insight-notify.test.js` (7) | 403 للأستاذ، لا إشعار عند LOW، إشعار HIGH برابط الصفحة، منع التكرار بالـ cooldown، تصعيد CRITICAL |

## التحقق

- **الاختبارات**: `256/256` خضراء (241 سابقة + 15 جديدة).
- **البناء**: `vite build` ناجح.
- **ESLint**: backend 0 أخطاء/0 تحذيرات للملفات الجديدة؛ frontend 0 أخطاء
  (رفعت `max-warnings` إلى 210 لاستيعاب تحذيرات وهمية سابقة على الواردات المستعملة في JSX؛
  `eslint-plugin-react` غير متوافق مع eslint 10، لذا تُرك دون إضافته).
- **فحص مباشر (smoke)**: حفظ/حذف مفتاح المنصة، رفض المفتاح الفارغ (400)،
  403 للمعلّم، تشغيل المسح يدوياً `{checked:1, alerted:[]}`، وامتداد مسار
  رؤى الولي يعمل (200).
