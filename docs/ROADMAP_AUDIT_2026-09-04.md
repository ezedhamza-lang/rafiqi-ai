| المحور | الحكم | درجة /10 |
|---|---|---|
| **الهندسة الخلفية** | قوية جداً، منظومة حقيقية (60 جدول، 296 endpoint، 46 خدمة، 31 validator، 27 ملف اختبار) | **8.5** |
| **الواجهة والتصميم** | Design System داخلي جاد + RTL ممتاز + وضع ليلي + PWA يدوي + 83 صفحة. حزمة 1.36MB بلا Lazy | **7.5** |
| **المطابقة البيداغوجية التونسية** | روح أصيلة، لكن **ابتدائي فقط 4 مواد**، رياضيات س2-س6 فهرس بلا محتوى، بنك «330» مضخَّم | **5.5** |

| **النشر والتشغيل** | Render يعمل، Free-tier محدود (سبات + قرص مؤقت + DB صغيرة) + Dockerfile كان مزدوج (أُصلح) | **6.0** |
| **المعدل العام** | مشروع جاد فوق المتوسط — **يصلح مساعد مراجعة، لا بديل كتاب رسمي بعد** | **6.8** |

**الحقائق الخمس الحاكمة:**
1. الحجم حقيقي: ~22K سطر backend + ~18K سطر frontend + 300+ اختبار — عمل شهور موثق
2. المحتوى نصفه فارغ: رياضيات س2-س6 = 276 عنواناً بلا شرح/تمرين
3. البنك الرسمي: 18 اختبار APC حقيقي + 240 تدريب مُعاد تغليفه + 36 مولد معطوب (`max<min`)
4. ثغرة حرجة: `/uploads` عام + Seed إنتاجي يعيد حسابات `*123` عند كل إقلاع
5. أداء: 1.36MB JS بلا Lazy، GitHub خاص (404)، لا `render.yaml`

## 4. المعايير غير القابلة للتفاوض (من التقرير)

1. **لا نسخ حرفي** من الكتب — تقليد أصلي: نفس الكفاية، نفس نوع السؤال، نفس مستوى الصعوبة، وضعيات وأرقام تونسية جديدة
2. **لا تختلق محتوى** — كل مادة جديدة تمر بمراجعة أستاذ + متفقد قبل النشر، ختم «رُوجِع» في `registry.json`
3. **فصل البنك الصارم** — رسمي موثق (18) / تدريب داعم (573) / مسودة آلية (36) — واجهات منفصلة، لا ترويسة رسمية على المسودات
4. **حماية البيانات** — `/uploads` عبر signed-URL، Seed معطل إنتاجي، أسرار خارج الريبو
4. **أداء مقبول** — Lazy loading، حزمة <500KB gzipped، `render.yaml` موثق
