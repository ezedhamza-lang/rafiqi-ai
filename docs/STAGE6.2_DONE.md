# المرحلة 6.2 — ربط بنوك الأسئلة الحقيقية بالدروس التفاعلية

تاريخ الإتمام: 17-08-2026
الحالة: **مكتملة (الموجة أ)** — التمارين التفاعلية لمواد السنتين الأوليين تصل للتلميذ من المحتوى الحقيقي (بنوك القوالب والأسئلة) دون اختلاق أي محتوى منهجي.

---

## قرار النطاق

المرحلة 6.2 الكاملة (حسب `docs/PHASES_SPLIT.md`) تتطلب توليد محتوى ضخم
للسنة الأولى × المواد (عربية، فرنسية، رياضيات، إيقاظ علمي، تربية إسلامية/مدنية،
تربية تشكيلية) ثم السنة الثانية.

لكن قاعدة المشروع في `curriculum/registry.json` (`_tracksNote`) صريحة:
**"لا نختلق محتوى، بس نجهّز الشكل"** — أي محتوى منهجي يجب أن ينبثق من مصادر
حقيقية. وُجد في الأرشيف:

| المصدر الحقيقي | الحجم | يستعمل لـ |
|---|---|---|
| `content/banks/templates-bank.json` | 573 تمريناً (عربية 148، رياضيات 152، إيقاظ 148، إنتاج كتابي 125) | الدروس والتمارين |
| `content/banks/question-bank.json` | 24 سؤالاً (حروف/أعداد/ألوان/مفردات) بإجابات | تمارين س1 المبسطة |
| `curriculum/year1/*` | رياضيات/أنيسي/إيقاظ كاملة | الأساس |

**غير موجود في الأرشيف** (ولا نختلقه): محتوى فرنسية، تربية إسلامية/مدنية، وتربية
تشكيلية، ومحتوى سنة ثانية بخلاف الرياضيات.

**القرار (بقرار المستخدم):** "Wire real banks into lessons" — ربط بنوك الأسئلة
الحقيقية بخط أنابيب الدروس التفاعلية لمواد السنتين الأوليين بدل توليد محتوى
مختلق.

## ما أُنجز

### 1. محوّل أسئلة البنوك إلى بلوكات موحّدة — `backend/src/services/curriculumService.js`

- `normalizeBankQuestion(q)`: يحوّل كل أنواع أسئلة `templates-bank.json` إلى
  بلوك `question` موحّد قابل للتحقق فورياً:
  - `mcq` / `complete` / `extract` → `options` + `answer` (رقم index).
  - `tf` → خيارات `[صحيح، خطأ]` + index.
  - `order` → نص مع خيارات مفصولة + إجابة الجملة المرتّبة كنص.
- `getBankTemplatesForSubject(code)`: ربط المواد بالبنوك:
  - `math` ← الرياضيات (152).
  - `anisi`/`reading`/`arabic` ← اللغة العربية (148) + إنتاج كتابي (125).
  - `science` ← الإيقاظ العلمي (148).
- `getBookExercises(subjectCode, level, gradeId)`: نقطة بيانات التمارين لكل كتاب —
  بنوك القوالب + بنك الأسئلة المبسّط (الحروف/الأعداد/الألوان/المفردات لس1).
  البنود الإنجليزية (`lang === 'en'`) تُتجاهل لبقاء المنصة عربية.

### 2. إثراء الدروس بالتمارين الحقيقية — `getLessonPages()`

كل درس في المواد المدعومة يُرفَق بـ 3 أسئلة تفاعلية حقيقية من البنك (توزيع
دوري حتمي عبر دروس الكتاب):

| المادة | الدروس | % تحمل سؤالاً قابلاً للتحقق |
|---|---|---|
| رياضيات س1 | 26 | 100% |
| قراءة (أنيسي) س1 | 28 | 100% |
| إيقاظ علمي س1 | 298 | 100% |

### 3. نقطة نهاية جديدة — `backend/src/routes/curriculum.js`

`GET /api/public/curriculum/books/:gradeId/:subjectId/exercises`
تعرض بنك التمارين التفاعلية الكامل للكتاب (قابلة للاستعمال من التلميذ).

### 4. تبويب «تمارين تفاعلية» — `frontend/src/components/LessonViewer.jsx`

- شريط تبويبين: **الدروس** | **تمارين تفاعلية** (مع عدّاد).
- عرض كل تمرين كبطاقة: نص الانطلاق + أسئلة تفاعلية (نفس مكوّن البلوكات،
  فيتحقق التلميذ من إجاباته فوراً).
- أنماط CSS جديدة في `frontend/src/index.css` (`.lesson-viewer-tabs`،
  `.lesson-exercise-bank`، `.lesson-exercise-card`، `.lesson-exercise-passage`).

## اختبارات جديدة (3) في `backend/tests/curriculum.test.js`

1. «تمارين من بنك القوالب الحقيقي تُثري دروس س1» — كل درس في المواد الثلاث يحمل
   سؤالاً تفاعلياً بـ `options` + `answer` صالح.
2. «نقطة نهاية التمارين تخدم مواد السنتين الأوليين بمحتوى حقيقي» — رياضيات س1 ≥150،
   قراءة س1 ≥150، إيقاظ س1 ≥148، رياضيات س2 ≥150؛ كل تمرين له عنوان وأسئلة قابلة للتحقق.
3. «لا مواد مزيّفة» — لا فرنسية ولا تربية إسلامية/تشكيلية بلا مصادر؛ مواد س1
   تبقى math/anisi/science فقط.

## ما لم يُنجز (موجة 6.2ب فما بعد)

- سنة ثانية بخلاف الرياضيات، ومحتوى فرنسية/تربية إسلامية/تشكيلية — **يتطلّب
  مصادر منهجية حقيقية** أو تفويضاً صريحاً لتوليدها. بموجب قاعدة «لا نختلق
  محتوى»، تُترك قيد الانتظار إلى أن تُوفَّر المصادر.
