## ما تم إنجازه

### 1. خدمة التحليلات `backend/src/services/analyticsService.js`
- `buildStudentReport` — تقرير تلميذ شامل:
  - `summary`: إجمالي التكليفات، المسلَّمة، نسبة الإنجاز، متوسط النسبة المئوية، عدد التكليفات المصححة.
  - `subjects[]`: لكل مادة (العدد، المسلَّم، متوسط النسبة، الحالة) — لبناء القوة/الضعف.
  - `strengths` / `weaknesses`: مواد تتجاوز/لا تبلغ عتبة 60% (مع عدد المسلَّم والتلميح) مع حدود قصوى لتفادي الضجيج.
  - `trend[]`: نقاط المنحنى الزمني (تاريخ + مادة + عنوان + نسبة) مرتبة صعودًا.
  - `alerts[]`: تنبيهات تعثر مبكر من 4 أنواع:
    - `LOW_COMPLETION` — إنجاز أقل من 50%.
    - `DECLINING_GRADES` — انحدار في آخر 3 تكليفات مصححة.
    - `OVERDUE` — تكليف متأخر لم يُسلَّم.
    - `LOW_AVERAGE` — متوسط أقل من 50%.
- `buildClassReport` — تقرير قسم:
  - `summary`: عدد التلاميذ، إجمالي التكليفات، نسبة الإنجاز الكلية، المتوسط الكلي، عدد التلاميذ المعرضين للخطر.
  - `students[]`: لكل تلميذ (المسلَّم، النسبة، المتوسط، `atRisk`).
  - `atRiskStudents[]`: المعرضون للخطر مع أسباب التنبيه.
  - `perAssignment[]`: متوسط إنجاز كل تكليف (لترتيب التكليفات الأضعف).

### 2. خدمة التصدير `backend/src/services/exportService.js`
- `buildGradesCsv` — CSV متوافق مع Excel العربي:
  - `UTF-8 BOM` + فاصلة منقوطة (`;`) + حقول نصية محاطة بعلامات اقتباس (دوال النص مُقيّمة بفواصلها).
  - الصف الأول: اسم القسم/المستوى، ثم رؤوس الأعمدة، ثم صف لكل تلميذ (الإنجاز، المتوسط، المواد بالتفصيل).
- `buildGradesPdf` — تقرير PDF منسّق:
  - رأس بالاسم، عمدان «القسم / المتوسط / التلميذ»، متوسطات التكليفات لكل تلميذ (بالمواد)، ونسب الإنجاز.
  - خط **Amiri** العربي مضمّن عبر `@pdf-lib/fontkit` (`backend/src/assets/fonts/Amiri-Regular.ttf` + `Amiri-Bold.ttf`) مع fallback إلى Helvetica — يضمن نصًا عربيًا RTL سليمًا في الملف المُصدَّر.
- `setAttachment` — ترويسة `Content-Disposition` بصيغة `filename*=UTF-8''...` لأسماء الملفات العربية.

### 3. مسارات API (محمية بالأدوار) + التحقق بـ Zod
| المسار | الدور | الوظيفة |
|---|---|---|
| `GET /api/teacher/analytics/class/:classId` | أستاذ/إدارة (قسم يخصّهم) | تقرير قسم شامل |
| `GET /api/teacher/analytics/students/:studentId` | أستاذ/إدارة (تلميذ بقسم يخصّهم) | تقرير تلميذ (قوة/ضعف/منحنى/تنبيهات) |
| `GET /api/teacher/analytics/export?classId=&format=csv\|pdf` | أستاذ/إدارة | تصدير نتائج قسم |
| `GET /api/student/analytics/self` | تلميذ | تقرير التلميذ لنفسه |
| `GET /api/parent/analytics/children/:studentId` | ولي (ابنه فقط) | تقرير الولي لابنه |

- ملفات جديدة: `src/routes/analytics.js`، `src/routes/parentAnalytics.js`، `src/validators/analytics.js`.
- مثبتة في `src/index.js` تحت `/api/teacher` و `/api/student` و `/api/parent`، ووسم Swagger `analytics` في `src/swagger.js`.
