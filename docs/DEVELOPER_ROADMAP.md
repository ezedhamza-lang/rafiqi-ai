# خارطة طريق المطوّر — منصة رفيقي
> محدّثة بتاريخ 06-09-2026. اقرأ هذا الملف أولاً قبل أي تعديل.

## 1. نظرة عامة
منصة تعليمية تونسية (ابتدائي): **PostgreSQL + Prisma + Express + React/Vite**، عربي RTL كامل.
- `backend/` — API على المنفذ 3001 (Express + Prisma، اختبارات vitest).
- `frontend/` — Vite + React (البناء ينتج `frontend/dist`).
- المحتوى الدراسي ملفات JSON في `backend/curriculum/` (رياضيات/قراءة/إيقاظ/إنتاج، سنوات 1-6).

## 2. النشر على Render (مهم جداً — اقرأ قبل الدفع)
- النشر تلقائي من فرع `main` عبر **`backend/Dockerfile`**.
- هذا الـ Dockerfile **يبني الواجهة من المصدر** (`COPY frontend/ + npm run build`) — لذلك:
- **ممنوع تسليم `frontend/dist/` في git** (ملفات بناء متولّدة، `.gitignore` يستبعدها أصلاً).
- `npm ci` صارم: أي تعديل على `package.json` **يجب** أن يتبعه `npm install` وتسليم `package-lock.json` المحدّث، وإلا فشل البناء بخطأ `Missing ... from lock file` (حدث فعلياً في 06-09-2026 بسبب قفل أعاد توليده npm 11 — أُصلح باستعادة القفل المتوافق).
- لا تستعمل `npm install` ثم تدفع القفل دون فحص `git diff` للقفل أولاً.
- نسخة Node في Docker‏: 20.x — التزم بها محلياً عند توليد القفل.

## 4. اتفاقيات المحتوى الدراسي (سنة أولى)
- كل درس: `studentBlocks` بأنواع `objective / concept / question / summary` (+ `drawing`, `textarea`, `picture-choice` عند الحاجة).
- كل سؤال **يجب** أن يكون قابلاً للإجابة: خيارات + `answer` (فهرس)، أو فراغ + `answer` (نص). المقارنة تتجاهل التشكيل (`normAns`).
- التقييمات: `isAssessment: true` + `subject` + `period` + `lessonTestId`، و**مجموع النقاط = 20 بالضبط** (يفحصه الاختبار).
- `noEnrich: true` يمنع حقن أسئلة البنك العامة في الدروس المؤلفة.
- النصوص مشكّلة بالكامل (تلاميذ 6 سنوات) والخط كبير.
- الصور: `frontend/public/{assessments,science,intaj}/` بأسماء مطابقة لمراجع `image:` في JSON.

## 5. اتفاقيات العمل المشترك (مهم — يوجد مطوّر آخر نشط)
- اعمل على فرع خاص بك، وادفع عبر PR أو بعد `git pull` — **ممنوع `push --force` وممنوع إعادة كتابة التاريخ**.
- يوجد `stash@{0}` بتاريخ سابق (d74daad: معايير وزارية) يخص عملاً جارياً — **لا تمسه**.
- ملف `كلمات-السر.md` محلي فقط (في `gitignore`) — أسرار التطوير فقط، لا تضع أسرار إنتاج أبداً.
- الباكند يخدم الواجهة المبنية من `frontend/dist` في الإنتاج (`express.static`) — لا تحذف مجلد `dist` من القرص المحلي.

## 6. بنود معلقة (ليست أعطالاً)
1. تدوير أسرار التطوير الموجودة في تاريخ git القديم عند الإطلاق الإنتاجي الحقيقي.
2. تقسيم حزم الواجهة (تحذير chunks > 500KB) — تحسين أداء مستقبلي.
3. واجهة تغيير أستاذ قسمٍ موجود (الـ API `PUT /director/classes/:id` جاهز).
4. اختيار طريقة الدفع في تسجيل الاشتراكات (ثابتة `OFFLINE` حالياً).
5. جدولا `skills-map`: لا يستهلكها أي كود حالياً (مرجع تسجيلي فقط).

## 7. أوامر سريعة
```bash
# باكند: اختبارات + فحص
cd backend && npm test && npm run lint
# واجهة: فحص + بناء
cd frontend && npm run lint && npm run build
# تشغيل محلي كامل
./start.sh   # أو: docker compose up --build -d
```
