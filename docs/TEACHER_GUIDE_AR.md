# 🎓 دعوة وتجربة منصة «رفيقي»

## دليل فضاء الأستاذة والأستاذ

### 🌷 مرحبًا بك في «رفيقي»

**يا زميلتي، يا زميلي العزيز،**

«رفيقي» ليست مجرد **منصة للأوراق والوثائق الإلكترونية**، بل هي فضاء مدرسي تونسي متكامل يجمع لك كل ما تحتاجه في عملك اليومي.

من خلال المنصة يمكنك:

* 👩‍🏫 برمجة أقسامك وموادك.
* 📚 إعداد الدروس والمذكرات والخطط.
* 📝 إنشاء الاختبارات والتكليفات.
* 🤖 الاستفادة من التصحيح والتحليل الآلي.
* 📊 متابعة مستوى كل تلميذ وقسم.
* 💬 التواصل مع الأولياء.
* 📅 إدارة الحضور والغياب والجداول.
* 🖨️ طباعة الوثائق والمعلقات متى شئت.
* 🤝 مشاركة مواردك مع بقية أساتذة المنصة.

**كل ذلك في فضاء واحد، وبصياغة عربية مدرسية تونسية.**

> 🚀 **تعالَ نكتشف أهم أدوات «رفيقي» خطوة بخطوة.**

# 1️⃣ التحليل والقياس

| الأداة | ماذا تفعل؟ | كيف تستخدمها؟ |
| --- | --- | --- |
| 📊 **تحليل الوحدات** | متابعة أداء التلاميذ حسب الوحدات والأقسام | افتحها لمتابعة إنجاز التلاميذ ونِسب التقدم في كل وحدة. |
| 📝 **الاختبارات** | إنشاء اختبارات إلكترونية متنوعة | اختر القسم ← أضف الأسئلة (اختيار متعدد، صح/خطأ، رتّب، أكمل) ← **«نشر»**. يتولى النظام التصحيح الآلي لحظة تسليم التلميذ. |
| 📋 **التكليفات** | إرسال واجبات منزلية رقمية | أنشئ التكليف ← حدّد القسم ← انشره. الأسئلة المغلقة تُصحَّح آليًا، والتسليم المتأخر يُرصد تلقائيًا في قائمة التسليمات. |
| 📈 **التحليلات والتصدير** | تحليل نتائج القسم واكتشاف نقاط القوة والضعف | اختر **«تحليل القسم»** لمتابعة المؤشرات وتنبيهات التعثر المبكر، ثم صدّر التقرير CSV أو اطبعه لمجلس القسم. |
| ✅ **التصحيح** | استقبال أوراق الاختبارات المصوّرة وتصحيحها | يرفع التلميذ صورة ورقة الامتحان من فضائه ← تظهر في طاولتك ← اعتمد **«التصحيح الآلي»** أو عدّل يدويًا، فتُعتمد النتيجة فورًا. |
| 🧾 **النتائج** | عرض نتائج التلاميذ في مكان واحد | ابحث باسم التلميذ لمشاهدة نتائجه في الاختبارات والتكليفات والامتحانات الرسمية. |
| % **المعدلات** | حساب ومقارنة المعدلات | لمتابعة متوسطات الأقسام والفترات والاستعداد لمجالس الأقسام. |
| 📖 **دفتر الدرجات** | شبكة شاملة: تلميذ × واجب/اختبار | يجمع ما تم تصحيحه في شبكة درجات رقمية دون إعادة إدخال العلامات يدويًا. |

# 2️⃣ المضامين والمصادر

| الأداة | ماذا تفعل؟ | كيف تستخدمها؟ |
| --- | --- | --- |
| 🧩 **مواد الأقسام** | برمجة مواد كل قسم وإسنادها لأستاذها | اختر **القسم** ← اختر **المادة** ← **«إضافة المادة»**. تُسنَد تلقائيًا لأستاذ القسم، وتظهر فورًا في «موادي» عند تلاميذه. |
| 📰 **المعلقات الرسمية** | إنشاء معلقات مدرسية جاهزة للطباعة | اختر القسم والدرس ← ولّد المعلّق ← **«طباعة»** بحجم A4 لتعلّقه في القسم. |
| 📄 **المذكرات** | إنشاء مذكرة درس وفق البروفايل المنهجي المعتمد | حدّد المادة والمستوى ونوع الدرس ← عنوان الدرس (وإن أخطأتَ العنوان، يقترح عليك النظام عناوين الدروس المرقمنة) ← **«توليد»** ← مذكرة كاملة بالمراحل والأنشطة جاهزة للطباعة. |
| 📅 **خطة الحصة** | إعداد خطة حصة 45 دقيقة كاملة | الأهداف والوسائل والمراحل والتقويم والواجب بنقرة — ثم احفظها أو اطبعها أو **«شاركها»** كمورد. |
| 🗓️ **التخطيطات السنوية** | توزيع الدروس على الفترات طوال السنة | أعدّ خريطة سنتك الدراسية مرة واحدة في مطلعها، ثم تتبّع تقدمك خلالها. |
| 📚 **الموارد التعليمية** | توليد أوراق عمل وواجبات وبطاقات وشرائح | اختر النوع والمادة والمستوى وعنوان الدرس ← **«توليد»** ← تُعرض كورقة رسمية: احفظها، أو اطبعها، أو اضغط **«مشاركة»**. |
| 🏛️ **مكتبة الموارد المشتركة** | الوصول إلى موارد أنشأها الأساتذة | فلتر حسب المادة والمستوى والنوع ← اختر المورد ← **«عرض»** أو **«طباعة»**. |
| 🧠 **رفيقي AI** | مساعد ذكي لإعداد المحتوى التعليمي | توليد خطة درس أو أسئلة أو ملخصات أو شرائح ← راجع ← **«حفظ كمورد»**. (يتطلب مفتاح ذكاء اصطناعي من إعدادات AI.) |

### 🤝 شارك واستفد

عندما تنشئ موردًا تعليميًا مميزًا، اضغط زر **«مشاركة»** البرتقالي لينشر في مكتبة الموارد المشتركة لكل أساتذة المنصة.

**أنت تنشر موردًا، وزملاؤك يشاركونك مواردهم.**

# 3️⃣ الحياة المدرسية اليومية

| الأداة | ماذا تفعل؟ |
| --- | --- |
| 🔥 **تقدم الدروس** | متابعة التلاميذ الذين أتموا كل درس تفاعلي، ومن يحتاج إلى مزيد دعم — دون انتظار نهاية الثلاثي. |
| 💬 **ملاحظات الأولياء** | استقبال رسائل الأولياء والرد عليها وتوثيق التواصل داخل المنصة. |
| 📆 **الحضور والغياب** | تسجيل الحضور والغياب بنقرة، مع **إشعار فوري للولي** عند تسجيل الغياب. |
| 🕐 **جدول الأوقات** | إنشاء جدول القسم (6 أيام × 6 فترات) وعرضه للتلاميذ والأولياء. |
| ❤️ **السجل الصحي** | حفظ المعلومات الصحية الضرورية للتلميذ في فضاء محمي وخاص بمدرسته. |
| 🎥 **الحصص المباشرة** | دروس عن بعد: محادثة، رفع يد، مشاركة شاشة، وتسجيل محفوظ بروابط آمنة قصيرة العمر. |
| 💡 **الاقتراحات** | توليد اقتراحات بيداغوجية جاهزة، وقراءة مقترحات تلاميذك. |
| 💳 **الدفع الإلكتروني** | متابعة الاشتراك وأدائه إلكترونيًا (بطاقة / STB / تحويل بنكي) دون إجراءات ورقية. |

# 🚀 يومك الأول مع «رفيقي»

**5 خطوات بسيطة في حدود 15 دقيقة:**

### 1️⃣ برمج قسمك
**مواد الأقسام ← اختر القسم ← رياضيات ← إضافة المادة**

### 2️⃣ أنشئ مذكرة درس
**المذكرات ← المادة والمستوى ونوع الدرس ← عنوان الدرس (مثل: «تعيين موقع شيء في الفضاء») ← توليد ← طباعة**

### 3️⃣ حضّر خطة الحصة
**خطة الحصة ← توليد ← ثم «مشاركة» لتظهر في مكتبة الموارد**

### 4️⃣ أنشئ اختبارًا
**الاختبارات ← اختر القسم ← أضف 5 أسئلة ← نشر**

### 5️⃣ تابع النتائج
آخر النهار افتح **التحليلات**، وستعرف:

* من أنجز النشاط؟ ومن لم ينجزه؟
* من يحتاج إلى دعم؟ وأين توجد الصعوبات؟
* كيف يتقدم القسم؟

# 👨‍👩‍👧‍👦 وماذا يرى التلميذ والولي؟

### 👦 فضاء التلميذ
يجد التلميذ مواده ودروسه التفاعلية وتكليفاته واختباراته ونتائجه وجداوله في فضاء خاص به — وحتى ورقة الامتحان الورقي يصوّرها ويسلّمها من هاتفه.

### 👨‍👩‍👧 فضاء الولي
تابع كل ما يخص ابنك/ابنتك:

* 📚 تقدم التعلم والتوأم الرقمي للنتائج.
* 📝 النتائج والعلامات والتقارير.
* 📆 الحضور والغياب والإشعارات الفورية.
* 💬 التواصل المباشر مع الأساتذة.
* 📁 رفع الوثائق (شهادات طبية…) ومراجعتها من الإدارة.

# 🌟 كل شيء في مكان واحد

> **من التخطيط إلى التدريس، ومن الاختبار إلى التصحيح، ومن النتيجة إلى التواصل مع الولي — «رفيقي» يجمع دورة العمل المدرسي في فضاء واحد.**

لا حاجة لإعادة كتابة المعلومات في أكثر من مكان: ما تنشئه ينتقل تلقائيًا بين المذكرات والموارد والاختبارات والتحليلات والنتائج.
