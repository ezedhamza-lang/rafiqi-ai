## ما أُنجز

### 1. بنك الاختبارات الرسمية — `backend/content/banks/official-exams-bank.json`

**18 قالب اختبار** بمحتوى حقيقي منسوخ من الاختبارات الرسمية:

| السنة | الثلاثي | المواد |
|---|---|---|
| س1 | 1 | رياضيات، قراءة، إيقاظ علمي، إنتاج كتابي |
| س1 | 2 | إيقاظ علمي |
| س1 | 3 | قراءة، رياضيات، إيقاظ علمي |
| س2 | 1 | قراءة، رياضيات، إيقاظ علمي، إنتاج كتابي، خط/إملاء |
| س2 | 2 | رياضيات، خط/إملاء |
| س2 | 3 | رياضيات، إيقاظ علمي، إنتاج كتابي |

كل قالب يحمل:
- **سندات** (نصوص الاختبار الأصلية).
- **معايير** `criteria` بجدول إسناد الأعداد: مستويات (انعدام/دون الأدنى/الأدنى/الأقصى) لكل معيار، ومجموع التملك الأقصى = **20 نقطة** (اختبار يُتحقق منه في الاختبارات).
- **أسئلة** بأنواع قابلة للتصحيح الآلي (MCQ، TRUE_FALSE، ORDER، FILL_BLANK، EXTRACT) + أسئلة مفتوحة (OPEN) تُرك للمعلم (قراءة جهرية، إنتاج كتابي...).

### 2. محرك الاختبارات — `backend/src/services/officialExamService.js`

- `loadOfficialExamBank()`: تحميل البنك مع cache.
- `listBankExams({level, subject, trimester})` / `getBankExam(id)`: فلترة ومعاينة.
- `buildExamContent(bankExam)`: تحويل القالب إلى بنية `OfficialExam.content` الرسمية (ترويسة + معايير + سندات + أسئلة).
- `gradeOfficialExam(content, answers)`: **التصحيح الآلي وفق جدول إسناد الأعداد**:
  - كل سؤال مغلق يُقارن بمفتاح الإجابة (تطبيع عربي).
  - لكل معيار: نسبة الإجابات الصحيحة ← مستوى تملك (انعدام/دون الأدنى/الأدنى/الأقصى) ← نقاط من الجدول.
  - المعايير بلا أسئلة مغلقة (قراءة جهرية، إنتاج، خط) تُعلَم `manualCriteria` للتقويم اليدوي.
  - النتيجة: `{ criteria[], total, totalMax, percent, manualCriteria, needsManualGrading }`.
- `officialExamSummary(content)`: معلومات التصحيح الآلي للعرض للمعلم.

### 3. نقاط نهاية API

**عمومية** (`backend/src/routes/curriculum.js` — `/api/public`):
- `GET /api/public/official-exams-bank?level=&subject=&trimester=`
- `GET /api/public/official-exams-bank/levels`
- `GET /api/public/official-exams-bank/subjects`
- `GET /api/public/official-exams-bank/:id`

**معلم** (`backend/src/routes/teacherContent.js`):
- `POST /api/teacher/exams/instantiate` — إنشاء اختبار من قالب البنك (توليد امتحان).
- `GET /api/teacher/exams/:id/preview` — معاينة مع ملخص التصحيح الآلي.

**تلميذ** (`backend/src/routes/teacher.js`):
- `GET /api/teacher/student/official-exams` — الاختبارات المنشورة لقسمه (مع الحالة وتسليمي).
- `GET /api/teacher/student/official-exams/:id` — تفاصيل **بدون مفاتيح الإجابة**.
- `POST /api/teacher/student/official-exams/:id/submit` — تقديم الإجابات ← تصحيح آلي فوري (نقطة/20 مع جدول المعايير)، منح XP، منع الإعادة.

### 4. واجهات المستخدم

- **`frontend/src/pages/teacher/OfficialExams.jsx`** (أعيد بناؤها): تصفّح البنك الرسمي الحقيقي مع فلاتر (سنة/مادة/ثلاثي)، معاينة السندات وجدول إسناد الأعداد والأسئلة، استيراد لاختباراتي، معاينة الاختبار مع جدول المعايير وطباعة بترويسة رسمية.
- **`frontend/src/pages/student/StudentOfficialExams.jsx`** (جديد): تبويب «الاختبارات الرسمية» في فضاء التلميذ — بدء الاختبار (سندات + أسئلة)، إرسال، ونتيجة رسمية بجدول المعايير والنقاط /20.

## اختبارات جديدة (8) في `backend/tests/official-exams.test.js`

1. البنك يحتوي اختبارات لكل ثلاثي/مادة متوفرة (س1 وس2، معايير، ثلاثيات 1/2/3).
2. كل قالب له جدول إسناد أعداد مجموعه 20.
3. المعاينة العمومية تفصّل سندات وأسئلة قالب واحد.
4. المعلم ينشئ اختباراً رسمياً من البنك (`instantiate`).
5. محرك التصحيح: صحيح كله → 20، خطأ كله → 0.
6. المعايير غير الآلية تُعلَم للتقويم اليدوي.
7. التلميذ يرى المنشور لقسمه ويتقدم بإجاباته فيُصحَّح آلياً (وعود الإعادة ممنوعة).
8. لا تظهر مفاتيح الإجابة للتلميذ.
