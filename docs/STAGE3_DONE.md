# المرحلة 3.1 — نظام التكليفات الأساسي (منجزة)

تاريخ الإنجاز: 14-08-2026
النطاق: الدفعة 3.1 من المرحلة 3 — حلقة التكليف الكاملة (إسناد ← إنجاز ← تصحيح آلي ← إشعار).
المرجع: `docs/PHASES_SPLIT.md` — الدفعة 3.1.

## ما تم إنجازه

### 1. نماذج بيانات Prisma
- `Assignment` — تكليف: الأستاذ، القسم، المادة، العنوان، الوصف، آخر أجل للتسليم (`dueDate`)، الأسئلة (JSON)، الحالة (`DRAFT` / `PUBLISHED` / `CLOSED`).
- `AssignmentSubmission` — تسليم تلميذ: الإجابات، التصحيح التفصيلي (`graded`)، الدرجة (`score`) والمجموع (`totalPoints`)، الحالة (`SUBMITTED` / `GRADED`)، ملاحظة الأستاذ، تاريخ التصحيح.
- ملاحظة تسمية: اقترحت الخطة `Assignment / Submission / Grade`، لكن نموذج `Submission` موجود مسبقاً لاختبارات القسم (Quiz)، فاعتمدنا `AssignmentSubmission` (يجمع التسليم + الدرجة) دون كسر الـ API الحالي.
- تهجير Migrations: `prisma/migrations/20260814170000_assignments/migration.sql` (تُطبّق عبر `prisma migrate deploy`).

### 2. مسارات API (محمية بالأدوار)
| المسار | الدور | الوظيفة |
|---|---|---|
| `GET /api/teacher/assignments` | أستاذ/إدارة | قائمة تكليفات الأستاذ |
| `POST /api/teacher/assignments` | أستاذ | إنشاء تكليف (مع إشعار لتلاميذ القسم) |
| `GET/PUT/DELETE /api/teacher/assignments/:id` | أستاذ | تفاصيل / تعديل / حذف |
| `GET /api/teacher/assignments/:id/submissions` | أستاذ | جدول متابعة (كل تلميذ القسم + تسليمه) |
| `PUT /api/teacher/assignments/:id/submissions/:submissionId` | أستاذ | تصحيح يدوي (درجة + ملاحظة + إشعار) |
| `GET /api/teacher/student/assignments` | تلميذ | تكليفات قسمه (مع حالة الإنجاز والتأخر) |
| `GET /api/teacher/student/assignments/:id` | تلميذ | تفاصيل تكليف (مع النتيجة إن أُنجز) |
| `POST /api/teacher/student/assignments/:id/submit` | تلميذ | إرسال الإجابات + تصحيح آلي فوري |
| `GET /api/parent/assignments` | ولي | تكليفات الأبناء + الدرجات والمواعيد |
| `GET /api/parent/assignments/:id` | ولي | تفاصيل تكليف لابن معين |

- التحقق من البيانات عبر `validators/assignment.js` (Zod) بنفس أسلوب المسارات الحالية.
- توثيق Swagger تلقائي (وسم `assignments`).

### 3. التصحيح الآلي
- يُعاد استعمال `gradingService.gradeQuiz` (موجود) للأسئلة الموضوعية:
  اختيار من متعدد (MCQ)، صح/خطأ (TRUE_FALSE)، ترتيب (ORDER)، استخراج (EXTRACT)، أكمل الفراغ (FILL_BLANK).
- عند الإرسال يُحسب لكل سؤال النقاط المكتسبة ويُخزَّن التفصيل في `graded`، مع الدرجة الكلية والنسبة المئوية.
- التلميذ يحصل على نقاط XP ونشاط يومي وشارات عند الإنجاز (نفس نظام الاختبارات).

### 4. الإشعارات
- إنشاء/نشر تكليف ← إشعار لكل تلميذ في القسم (`ASSIGNMENT`).
- إرسال التلميذ ← إشعار للأستاذ (`ASSIGNMENT_SUBMITTED`) وللولي.
- التصحيح (آلي أو يدوي) ← إشعار للتلميذ والولي (`ASSIGNMENT_GRADED`).
