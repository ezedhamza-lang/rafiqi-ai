# مغامرة رفيقي – حديقة المعرفة

**Rafiqi · Knowledge Garden Adventure**

لعبة مغامرة ثلاثية الأبعاد تعليمية داخل منصة **رفيقي**. يتحكّم فيها التلميذ
بالشخصية الرئيسية — البومة الزرقاء **رفيقي** — بين سبعة عوالم تعليمية.

## 1. أين اللعبة؟

| | |
|---|---|
| الرابط داخل المنصة | `/games/letters-garden` |

`<iframe>` مع الحفاظ على الهيدر وتخطيط RTL وحساب الطالب كما هو.

> ملاحظة: يوجد مجلد قديم غير مكتمل في `public/games/letters-garden/` من نسخة
> سابقة (بلا `index.html` ولا يعمل). اللعبة الحيّة هي `public/games/knowledge-garden/`.

## 2. المبدأ التربوي

اللعبة تتبع دورة:

```
لعب ← تعلّم ← تدريب ← إتقان ← مكافأة ← فتح
```

وليس: `لعب ← سؤال ← نقاط`

| القاعدة | مكان التنفيذ |
|---|---|
| لا عقاب على الخطأ أبداً | `computeScore` لا يطرح أي نقاط |
| الخطأ يُدرّس ولا يُحبط | صوت لطيف + اهتزاز بسيط + تلميح + محاولة أخرى |
| الإتقان هو المقياس لا السرعة | النجوم من الدقة، لا من الوقت |
| التدريج قبل الاختبار | كل مرحلة تبدأ بـ warm-up قبل أي اختبار |
| لا تسلّم أبداً | `practiceQueue` يحقن تدريباً إضافياً تلقائياً |

## 3. المحتوى — 7 عوالم، 35 مرحلة

| # | العالم | المحتوى |
|---|---|---|
| 1 | 🌱 حديقة الحروف | تمييز الحرف، البحث داخل الكلمات، ربط الحرف بالصوت، المقاطع، بناء الكلمات |
| 2 | 🌳 غابة الكلمات | كلمة للصورة، إكمال الناقص، ترتيب الحروف، كشف الخاطئة، القراءة |
| 3 | 🏡 قرية الجمل | ترتيب كلمات الجملة داخل العالم |
| 4 | 🏰 قلعة المعرفة | فهم، مفردات، قواعد، أرقام، منطق |
| 5 | 🌋 وادي التحديات | تحديات مؤقّتة + منصات متحركة + شلالات |
| 6 | ☁️ مدينة المعرفة | أرقام ومنطق وجُمل في مدينة عصرية |
| 7 | ⭐ جزيرة الأبطال | خلط متقدّم لأهم المهارات |

**بنية المرحلة العادية** (٥ إيقاعات):
`تسخين → أساسي → منصات → متقدّم → ختامي → شاشة المكافأة`

**مرحلة الزعيم** (كل خامس مستوى): ١٠ تحديات، وزعيم في العالم يتقلّص مع كل إجابة صحيحة.

**التدرّج:** ١–٥ سهل جداً · ٦–١٠ سهل · ١١–١٥ متوسط · ١٦–٢٠ متوسط صعب ·
٢١–٢٥ صعب · ٢٦–٣٥ تحدٍّ. المؤقتات لا تظهر قبل العالم الخامس.

## 4. نظام الإتقان

كل مهارة لها سجل دائم على الخادم يمرّ بست مراحل:

```
تمييز ← تعرّف ← تطبيق ← بناء ← تحدٍّ ← إتقان
```

| mastery | الحالة |
|---|---|
| ≥ 70 | ✅ متقن |
| 35–69 | ⚠️ يحتاج تدريب |
| < 35 | ❌ يحتاج مراجعة |

- **النمو سريع** (٧ نقاط في البداية) لأن الطفل يحتاج شعوراً بالتقدّم.
- **الاضمحلال لطيف** (٢–٦ نقاط): الخطأ يوجّه ولا يعاقِب.
- `practiceQueue` يرتّب أضعف ٣ مهارات؛ اللعبة تحقنها في المرحلة التالية.

**التكيّف أثناء الجولة** (`RunState`): ارتفاع معدل النجاح ⇐ صعوبة أعلى، معاملات
أصعب ووقت إضافي ومُشتّتات أكثر. تعثّر ⇐ صعوبة أقل، وتلميحات، وعالم أبطأ، وتكرار لطيف.
الحدود مضمونة: `0 ≤ difficulty ≤ 2`.

## 5. الأمان: الخادم هو المصدر الوحيد للحقيقة

> **المتصفح لا يرسل أي نقاط ولا نجوماً ولا جواهر.**

`toSubmission()` يرسل **العدادات فقط**:

```js
{ levelId, worldId, correct, wrong, total, timeSec, bestStreak, hintsUsed, skills: [...] }
```

والخادم يحسب كل شيء في `knowledgeGardenService.js`.

| الحماية | التنفيذ |
|---|---|
| تعديل الحمولة | مخطّط zod **يتجاهل** أي حقل غير معروف (`score`, `stars`…) |
| تضخيم الإجابات | `safeCorrect = min(correct, total)` |
| تخطّي المراحل | فحص `completedOrders` قبل قبول أي نتيجة |
| إعادة اللعب | المكافآت لِفرق النجوم الجديد فقط |
| أفضل نتيجة | `bestScore` بحدّ أقصى حقيقي عبر `updateMany` |
| تحدي اليوم | `dayKey` مقابل تاريخ الخادم + قيد `unique` + `409` |
| التخصيص | لا يُقبل عنصر إلا إذا كان مفتوحاً فعلاً |

## 6. التحكّم

| | |
|---|---|
| **سطح المكتب** | `W A S D` أو الأسهم · `مسافة` قفز · `Shift` انطلاقة · `Esc` إيقاف |

## 7. الصوت

كل الأصوات مُولّدة عبر **Web Audio API** — لا ملفات صوتية، يعمل دون اتصال.
نبرات قصيرة ودافئة: قفز، إجابة صحيحة (سُلّم يتصاعد مع السلسلة)، خطأ لطيف،
نجمة، جوهرة، نهاية مرحلة، وزعيم.

## 9. الاختبارات

```bash
# منطق اللعبة (بدون متصفح)
node --test frontend/public/games/knowledge-garden/test/game.test.mjs

# اللعبة في متصفح حقيقي
node --test frontend/public/games/knowledge-garden/test/browser.test.mjs

# تشخيص
node .../browser.test.mjs --diag     # أخطاء الكونسول
node .../browser.test.mjs --play     # حتى مرحلة اللعب
node .../browser.test.mjs --layout   # مواضع عناصر الواجهة

# الخادم
cd backend && npx vitest run tests/knowledge-garden.test.js
```

**النتائج الحالية:** ٢٢ منطقي · ١٠ متصفح · ٢١ خادم — كلها ناجحة.

يتحقق اختبار المتصفح من: إقلاع بلا أخطاء · WebGL · شاشة البداية · الخريطة
(٧ عوالم / ٣٥ مرحلة) · شاشة التعريف · بدء اللعب وظهور التحدي · التوجيه
والقفز · الإيقاف · لقطات · **وعدم وجود أي عنصر خارج الشاشة أو متداخل** على
سطح المكتب والجوال.
